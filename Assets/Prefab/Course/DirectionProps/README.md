# コース誘導用オブジェクト

SceneへPrefabをドラッグして配置します。地面の位置がルートのY=0です。

| Prefab | 形状・寸法 |
| --- | --- |
| ArrowGuardrail | 幅6m、高さ1.4m。両面に白地・赤の連続矢印、赤い縁取り |
| ArrowSign | 幅1.9m、高さ2.575m。両面に白地・赤矢印、赤い縁取り |
| NoEntryPole | 高さ約1.8m、台座幅0.64m。黄黒の斜め縞 |

矢印はどちらの面もローカル+X方向を示します。逆方向にする場合はPrefab全体をY軸で180度回転してください。道路沿いの向きに合わせてY回転を調整できます。

全種類に静的Colliderを設定済みです。ポールは進入禁止の境界に複数並べて使用してください。ポール間の隙間には当たり判定はありません。

通常のMesh・URP Materialを保存したPrefabなので、実行時生成スクリプトは不要です。再生成はUnityの `Racing > Create Course Direction Props` から実行できます。この操作は同名のPrefabとMaterialを上書きします。個別に加工する場合は先に複製してください。
