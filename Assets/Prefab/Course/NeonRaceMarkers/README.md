# ネオン開始線・ゴールゲート

タイトル画面の暗い背景とシャープな文字に合わせた、ミッドナイトメタル／シアン／ピンクの3Dオブジェクトです。

| Prefab | 内容 |
| --- | --- |
| NeonStartLine | 幅16mのチェッカー開始線、STARTの立体文字、進行方向マーク、左右の発光ビーコン。全幅17.9m、高さ1.315m |
| NeonGoalGate | FINISHの両面立体文字、発光アーチ、チェック柄、路面の通過ライン。全幅19.2m、高さ約7.14m、奥行2.4m |

## 配置

PrefabをSceneにドラッグし、ルートのY=0を路面に合わせます。ローカルXが道路の幅方向、+Zが進行方向です。開始線の基準位置はチェッカーの中心、ゲートはアーチ直下の通過ライン中心です。

標準は幅16mの道路用です。道路幅に合わせてルートのXスケールを調整できます（文字や柱の幅も一緒に変わります）。ゲートの開口は地上約5mまで幅16mを確保しています。

配置位置はコースごとに調整してください。既存のSampleSceneは自動変更しません。既存のGoalオブジェクトに合わせる場合は、そのトリガーの中心とゲートの通過ラインをそろえてください。

## 描画と判定

- URP Litの発光マテリアルを使用。Bloomが有効なカメラではネオンの光がにじみます。Bloomなしでも発光色を表示します。
- 文字を含めて保存済みMeshで構成しているため、フォントや実行時生成スクリプトは不要です。
- 各Prefabは5つのMeshRendererにまとめています。リアルタイムライトは追加していません。
- 視覚的な目印専用です。ColliderやGoalSensorは含みません。ラップ／ゴール判定は既存のGoalSensorを利用してください。開始線が車の走行を妨げることはありません。

## 再生成

Unityの `Racing > Create Neon Start Line and Goal Gate` で再生成できます。同名Prefab・Mesh・Materialを上書きするため、個別に編集したバリエーションは複製して保存してください。

生成コード: `Assets/Editor/NeonRaceMarkersBuilder.cs`

プレビュー: `Artifacts/NeonRaceMarkers.png`（Unityでレンダリング、開始線をゲートの3.5m手前に配置）
