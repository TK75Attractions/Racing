# ペダル保持での決定と全ウィンドウ再配置（2026-10-31）

タイトル・結果・終了・車選択の決定から、ペダルの事前解放条件を削除した。画面の遷移待ち・入力待機時間・長押し時間は維持する。練習も最初の解放なしで開始し、コース説明は最低4秒を表示した後、踏み続けた入力でも先へ進む。走行中の再接続や自動運転OFF時の手動復帰に使う解放確認は維持する。

管理画面の「ゲーム設定 → 画面の配置」に再配置ボタンを追加した。P1/P2は初回の外部ディスプレイ割り当て、観戦は起動時の割り当てへ全画面で戻す。画面のUUIDを保ち、切断中の割り当てを他画面へ移さない。通常のディスプレイ監視では観戦画面の手動移動・閉じた状態を保ち、明示的な操作時のみ戻す。観戦機能が有効なら閉じた観戦画面を開き直す。
