# MacBook埋込観戦窓の構造案

既存のレースゲーム筐体の中央側面に、MacBookを開いたまま収める設計検討。
構造の決定・施工承認・耐荷重証明を目的とした図面ではない。

## 成果物

- `output/pdf/macbook-recessed-mount.pdf`: A3横3ページ。外観・断面・支持枠・取り出し方・部材候補・モデルとの関係。
- `output/macbook-recessed-mount-preview.png`: 1ページ目のレンダリング。
- `mount-parameters.json`: 仮の機器寸法、角度、座標と収納寸法。
- `build_mount_proposal.py`: PDFとパラメータを再生成するソース。

## 設計条件

機種は未確認。MacBookの仮外形は幅360、奥行250、本体厚18、画面側長さ250 mm。
開き130度、画面上端が観客側へ20度、本体側が水平から下へ60度となる姿勢。
収納内空は幅400、高さ520、奥行170 mmを候補とする。
本体と画面の計算上の最大奥行は約151 mm。支持材を足すと約160 mmになる。

表板480×560×厚12 mm、視窓400×270 mm。外への突出は表板とねじ頭程度。
表板と傾斜台を別に取り外し、MacBookを載せた台を観客側へ抜く。
本体の縁と底面受けで支持し、ヒンジや画面から吊らない。

## 元モデルと干渉

読み取り元は以前の作業で保存した `racing-cabinet-flow.blend` と、元OBJから抽出した
部材別AABB `geometry.json`。元モデルの実寸単位は未確認。

中央側面はX=60.3 U、中心Y=-46.3 U。
縦材 `ボディ1:29` と `ボディ1:209` は観戦窓と重なる。
薄い側板だけに穴を開ける案では成立せず、上下枠に接合した新しい支柱へ置き換える案とした。

仮に1 U=10 mmなら、収納深さ170 mmの内端はX=43.3 U。
内側の既存縦材は最大X=43 Uであり、境界の差は約3 mmしかない。
これは配置検討の条件であって、施工余裕を保証しない。
追加支持材・ケーブル・実物のばらつきを含めた実機合わせが必要。

## 未確定事項

- MacBookの型番・実外形・端子位置・可動角度。
- 筐体の実寸、柱の材料、上下枠の接合、許容荷重。
- 台の端子逃げ形状、接合金物の配置と容量。
- 観客位置から画面四隅が見える視窓寸法。奥まるほど横から見切れやすい。
- 運転中の排熱。内部を密閉せず、本体底面・キーボード・排気口を覆わない。
