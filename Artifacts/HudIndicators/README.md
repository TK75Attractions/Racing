# 太い操舵表示・スピードメーター外周の加減速表示

2026-10-18（日本時間）、Unity 6000.3.9f1。

- 下端の操舵表示を約3倍に太くし、暗い下地とカーソルの縁取りを追加。
- スピードメーター外周に実際の速度変化を示す弧を追加。加速は青で時計回り、減速は赤で反時計回り、一定速・停止は消灯する。
- スピードメーター下の旧ペダル・小型ハンドルパネルを撤去。

## 検証結果

`HudIndicatorValidation.RunBatch` が終了コード0で完了。速度の微分、加減速の符号、一定速・停止、リセット後の誤表示防止、表示上限、微小ノイズ時の再描画抑止を検査した。10 m/s²の速度ランプを0.6秒与えた結果は、50 Hz・100 Hzとも9.933 m/s²で、サンプリング頻度によらず同じ平滑化を確認した。

両プレイヤーのModern UI検証と既存のHUD更新・ボタン・アイドル時の回帰検証も通過。6枚のプレビューで字形の欠落・文字切れがなく、加速・減速・一定速と旧パネル撤去を目視確認した。フォント再生成直後の字形キャッシュも更新し、「減速」が同じ検証実行で表示されることを確認している。
