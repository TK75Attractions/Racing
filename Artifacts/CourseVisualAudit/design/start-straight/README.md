## 元三角形から得られた制約の衝突

`corridor-conflict.json` は `C:/RC/Artifacts/CourseVisualAudit/near-road-renderers.obj` を直接読み、木の元三角形をクリップして得た値である。OBJのSHA-256は既存 `outlines.json` と一致する（`0d8715fee0e3e0ceaeca4b10412bb5d32b7d1e64fd75a7e7161c013e870846a9`）。木の凸包に出た偽陽性に基づく結論ではない。

| 条件 | ワールド座標・距離（m） |
| --- | ---: |
| 地面 `1016こうしゃ/Plane` の北端 | z=860.000041 |
| 棟 `Cube.008/Cube.009` の元の北端 | z=843.500012 |
| 棟を地面内に保てる北移動の上限 | 16.500029 |
| 棟 `Cube.008` 南面の元の位置 | z≈805.550 |
| 元の円弧の路面+6mでの外向き張り出し | 10.392305 |
| 上限まで移動した棟を避ける水平直線の中心線 | z≤801.657717 |
| `tree.017` の元三角形が要求する中心線 | z≥805.844530 |
| 両者の不足 | **4.186813** |
| この木と棟の南面だけから必要になる北移動の下限 | **20.686842** |

木の証拠点は `1016こうしゃ/Cube.026/tree.017` の世界座標 `(392.566071, 8.466369, 785.784058)`。その高さは路面+5.466369mで、元の下側円弧16区分の内面を使用する。

中心線を `c`、木の高さでの円弧張り出しを `r(h)`、棟の北移動を `d` とすると、幅20mの水平直線には次が必要となる。

```text
c >= tree.z + 10 + r(tree.y - 3) = 805.844530
c <= wall.south.z + d - 10 - r(6)
d <= 860.000041 - 843.500012 = 16.500029
```

棟南面の元ポリゴンもJSONに保存した。出入口の切り欠きは高さ約6.5m以下であり、路面+6m（世界y≈9m）付近には壁がある。境界接触・座標の微小誤差を考慮しても、不足は4m以上ある。これは最も基本的な水平の東西直線に対する必要条件であり、前後の角の調整でこの直線中央部の不足は解消できない。傾斜した任意の直線や、高さを変更する経路の全探索は行っていない。

元の直線 `(496,3,785.6693)` → `(258.2,3,796.7)` の方位をそのまま保つ場合も、木と棟の上端を同じ北向き法線へ射影して確認した。必要な棟の移動の下限は **24.472153m** となり、地面内上限16.500029mを超える（`original_heading_preserved`）。したがって、元の斜めの直線をそのまま北へ平行移動する案にもこの衝突がある。

## 配置候補と線形の確認

`verification.json` は7候補について、通常1.5mと細分化0.25mで丸め後の線形・幅・道路三角形を計算し、前後の角を含む北側の地上区間（生成区間の少なくとも一端がz>775m）についてA/Bを検証する。Aは道路端+0.5m、0〜6m、Bは道路端から元の円弧バリア内面まで、0〜6m。ネイティブの全サンプル接続点を残し、幾何クリップ区間は0.5m以下に分割する。木は保守的な0.5m高さ帯の凸包、建物は完全FBXポリゴンを使う。元の近傍OBJにない新経路側の建物を見落とさないよう、建物の旧近傍三角形への限定はしない。

全候補の直線両端は `(494.7,3,z)` と `(258.2,3,z)`。チューブ・ジャンプ・着地の元制御点は変更していない。以下は診断用の不採用候補であり、角の接続点を確定した実装設計ではない。

全候補で最小幅12m、細分化での最大幅変化率0.199763m/m以下、全長変化+0.966〜+1.595%（通常・細分化の両方を含めると+0.964〜+1.595%）、道路三角形の反転0枚である。頂点float32丸めでも反転0枚。幅20mの水平直線化だけでは北東角が通常24.758m／細分化24.749mとなり、25m条件に不合格。開始時の通常サンプリングの北東角は約25.760mである。`all_ground_corners` はチューブ・路面のないジャンプを除く全地上の角を、`northeast_corner` はホームへ入る北東角を、周回継ぎ目を含めて別途記録する。既存 `predict.metrics` の `min_radius` は踏切接近路に限定した指標なので、北東角の合格判定には流用しない。

点ごとの半径を全地上へ拡張すると、西側接続や着地からチューブへ移る付近で25m未満の値も出る。開始時にも通常19.809m／細分化8.895mがあり、候補には約5.9〜6.0mの値がある。既存の5m窓評価と同一の指標ではなく、候補について全周の半径条件が合格したとは扱わない。別の成立案を作るときにはこの接続部とチューブ手前の元の線形を維持し、採用する半径指標をそろえて再検証する必要がある。

23m移動・z=807mでは対象のA/B侵入0を確認できるが、棟の北端はz=866.500012mとなり、地面北端から6.499971mはみ出す。したがってこの配置を本番制御点・移動表へ書き込むことはしない。

## 棟の離隔と足元

16.4m移動の診断候補は、棟に属する6 RendererすべてのXZ外接矩形が、主地面の実際の塗りつぶしポリゴン内に入る。外周矩形だけでなく、凹部と地面境界の横切りも確認する。元位置と移動後の足元の地面高さをポリゴン平面から評価し、地面高さの差をRendererごとに記録した。棟本体の足元は元の世界y≈0mで、平面の微小傾斜による差は1mm未満。子の屋根等は棟との相対位置を維持する前提で、すべての子が地面へ接するという意味ではない。y・回転・スケールの変更は計算に含めていない。

他の校舎物体とのAABB最短離隔の下限は **7.824949m**（`Cube.008` と `人間.007`）。実形状間距離以上にはならない保守的な下限なので、0.3m条件を満たす。支持する主地面と、移動する同じ棟内部の接合は他物体との離隔から除く。木の移動は0本。これらは採用案ではなく、地面内に置ける診断候補についての値である。
