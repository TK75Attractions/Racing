# アイテム改善の検証画像・記録

- `mystery-box.png`：実メッシュ・マテリアルの拡大描画。
- `guide-*`、`rocket-*`、`confuse-*`：実HUDと固定の検査状態。背景には既存の参照画像を使用しています。
- `practice-03-item.png`、`practice-04-wait.png`：実車を走らせた練習の録画フレーム。取得前と停止後の効果一覧です。
- `verification.json`：検証件数・範囲・未検証事項。
- `race-report.json`、`race-events.json`：CPU2台とアイテムを含む本番コース走行の記録と、取得・被弾・終了イベントの抜粋。

手順と評価過程は [Documentation/ItemFirstPlay.md](../../Documentation/ItemFirstPlay.md) を参照。
