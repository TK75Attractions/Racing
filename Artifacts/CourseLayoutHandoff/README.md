## 再生成の安定性で修正した点

PhysXで再cookしたチューブへのレイが入口で約0.24mm揺れ、Plane013/017の切り抜き結果が異なることを再現した。前後の元Mesh/TRSは同一、差は入口clip planeの16行だけだった。CourseBuildingClearanceのベイク時判定を、同じPhysics用TRSの元三角形への倍精度両面レイ判定に変更した。実行時のチューブ/バリア衝突処理は変更していない。

引き継いだI1では、入口角の探索が全長の1/4に制限される問題も修正した。復帰検証の移動車が固定Xで変形壁の外へ出ていた計測は、実際の壁面に沿う検証へ修正。見た目監査は左右・区間ごとの断面に対応し、最終実行では不要なOBJ再出力だけを省略した。

## 許容・範囲外と限界

全周の見た目侵入0を主張しない。既存のホーム南端z≈644.914のPlane.019のA侵入約1.018m（道路端+0.5mの余白を含む）、許容されたホーム右の柱、対象外の西側昇降口と頭上の既存物体は維持。Aは走路端+0.5mの0〜6m帯、Bは道路端からバリア内面までの0〜6m帯で、監査領域は最大0.5mの区間線形近似。

最終実走では対象外の着地後Plane.012/Plane.017に1件接触した（世界626.088,11.482,587.066、路面中心線からの高さ3.018m。既存の衝突切り抜き上限3mを超える）。3車線ともバリア接触があり、中央車線には大減速2件がある。全周の無接触・車線追従精度を保証する結果ではない。既存のDriftChargeVisual.cs:81のRaceParticipantに対するGetComponent例外も継続しており、今回のコース変更とは分けて記録する。既存の表示不具合を修正したとは扱わない。
