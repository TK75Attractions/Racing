# 2026-10-23 ゲーム・運営画面の改善

## 実装

1. P1/P2が使用するDisplayを予約してから中継画面の出力先を決める。EditorのP2=Display 3設定では中継はDisplay 2。Macの独立した第3ウィンドウは維持する。
2. 遠隔操作を開始せずに復帰を実行できる。元の入力元・遠隔操作の占有を変更せず、通常の安全な復帰処理を呼ぶ。車のないタイトル等では拒否する。
3. F8／管理画面からP1 AUTO vs P2 AUTOの2周レースを開始できる。操舵・ペダル入力で走行し、日次ランキングには記録しない。P2の元の自動運転設定は両者AUTOモードだけでは変更しない。
4. 練習の第3段階を「光る箱に触れてアイテムを取る」に変更。専用コースに本番と同じTrigger方式の箱を配置し、実際に接触した自分の車だけが取得・完了する。シールドと取得音も発動する。
5. CPUが人間との接触後にコライダーを無効化していた処理を撤去。回避操舵・減速による譲りは保つ。完走後のウイニングラン車が走行車を妨げない従来の扱いは維持する。
6. 後着プレイヤーのゴール演出を観戦側にも同じ名前・タイムで表示。僅差で先着側の演出が残っている場合も後着のゴールへ更新する。
7. 機器カードから診断画面を開く。新しい状態・設定照会と待機時のI2C検索を使い、確認できた事実、原因候補、点検箇所を区別する。校正等の設定変更は自動実行しない。未使用センサーや正常な0%ペダルを故障扱いしない。
8. F8／管理画面の機能切替を指定の6項目だけに整理。他の改善は通常操作で無効化できない標準機能にする。過去のA/B検証は明示的なEditor専用APIへ分離する。
9. 16分割の順序付きコース通過と正味の走行進捗を確認し、正方向のゴール通過でだけ周回を計数する。ライン往復、逆走、復帰、重複コライダー通知では周回が増えない。
10. iPhoneのホーム画面アプリ向けWeb Push。リレーが画面と独立して異常を監視し、端末ごとに許可された購読へ暗号化通知を送る。初期準備・未使用入力・校正中の意図的な配信停止を区別し、継続障害の連打を抑制する。常駐版を既存設定のまま更新するコマンドを追加した。

- 基本テスト149件、Dashboard UI／診断／Service Worker／許可操作のテスト51件が通過。
- Web Pushプロトコル31項目が通過。生成した本物のaes128gcmリクエストをテスト用受信鍵で独立に復号し、VAPID署名も検証した。HTTP受信先はテスト用処理であり、Appleや実端末へテストメッセージを送っていない。
- 分離した19765/19766ポートで実通信・Chrome操作の統合テスト32件が通過。環境依存のPTY試験1件はスキップ。操作権限、購読の所有者、任意URL拒否、復帰の非占有、自動対戦、PC／390px幅のレイアウトも確認した。
- 実際のSampleSceneでP1/P2自動運転がそれぞれ2周完走。P1 106.8207秒、P2 101.4874秒。運転入力以外で位置・周回・結果を注入していない。走行中の全車両ペアが衝突有効のままであること、操舵入力、両画面の後着ゴール表示を検査した。CSVは観測した入力と物理状態。
- 練習をP1/P2独立の操舵・ペダル入力で完了。1→2の位置・向き・速度の連続性も確認。連続性の単体確認だけは一時的に初期状態を設定して比較し、その後元へ戻して実走する。新しい日本語文言の静的グリフを追加し、最終走行に欠落グリフ警告がないことを確認した。
- 本番プレハブの独立物理シーンで90m/sの正面衝突・追突、65m/sの側面接触を確認。車は前後・左右をすり抜けず、追突では相手へ力が伝わる。
- Unityでライン往復・逆走・正しい2周・復帰・重複通知を検査。既存機能のEditor比較検証も通過。
- Unity 6000.3.9f1のMacビルド成功。実行ファイルの新規起動／保存履歴あり起動でPV／REPLAYを確認し、内蔵画面全面3360×2100、描画エラー収集0件。

## 実機の常駐Dashboard更新

macOSのlaunchdが停止登録を退役させるまで短く待ってから起動する処理を加え、実機の常駐Dashboard更新が成功した。Tailscale接続先・操作権限・配信元を含む既存plistのハッシュは完全に一致。稼働中の通知API、Service Worker、manifest、アイコン、通知UI配信を確認した。通知許可はiPhoneでの初回タップが残る。実端末へ無断でテスト通知は送っていない。

mainの作業フォルダに元からあったシーン・マテリアルの未commit差分は同一のまま保持した。既存のフォント編集13項目は、新グリフのアトラスと参照IDを維持しながらプロパティ単位で戻した。一時保管した当作業専用stashは検証後に削除し、以前からのstashには触れていない。
