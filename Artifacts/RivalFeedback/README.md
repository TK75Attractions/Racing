実際のSampleSceneを、人間に近い反応間隔で車の状態を観測し、ハンドル角・ペダルを入力する既存ボットで走行した。入力は通常のInputManager／入力ゲートを通し、レース車両の位置・姿勢・速度を直接操作していない。妨害通知を再現するため、通常の `UseItem` からP1→CPU 1、P2→P1のコンフューズをテスト発動した。ジャンプ付近などで妨害が拒否された場合は、成立するまでテスト発動を試みる。通常アイテム箱の抽選確率やレースバランスを測る試験ではない。

映像はP1の実カメラとHUDを1280×720・24fpsでオフライン収録し、約12秒のコース紹介・カウントダウンを除いた20秒を保存した。描画FPSの測定ではない。23秒の走行観測と終了待ちを含む元動画・ログは `Logs/RivalFeedback/FinalReady`。b38bbc6を基点に今回の作業ツリーを適用した状態で収録。画像はP1/P2それぞれのカメラから取得した。

## 確認結果

- 接近・距離・相対速度・並走・別階層／別区間・遮蔽・周回境界・不正値の判定を含む単体テスト114件成功、失敗0。`core-tests.xml`。
- 最終23秒の通常走行で、両画面の延べフレーム数として前方表示215フレーム、後方表示255フレームを観測。近距離の3D矢印の実寸と、カメラの画面内への収まりを確認。`Final/rival-feedback-checks.json`。
- カメラの描画開始を1,944回観測し、3D矢印が他プレイヤー・UI用カメラへ混入しないことを確認。
- P1がCPU 1へ与えた反転はP1画面へ、P2がP1へ与えた反転はP2画面へ、対象名付きで通知された。
- 別の専用試験車体で、シールド／ロケット／復帰保護／無効化済み車／自己被弾／連続被弾保護による誤通知がないことを確認。油だまりが保持する発動者と、一度だけの消費も確認。
- 専用試験車体の実際のオイルTrigger、シールドCollision、反転中の静的な壁へのCollisionから、それぞれ正しい発動者・対象の成立イベントを確認。専用車体だけは試験用の配置・速度を与えており、通常走行の成績とは区別した。
- F8相当で両機能をOFFにすると表示・3D Mesh・保留通知が消え、ONへ戻せる。走行中の例外0。`Final/report.json`。完走試験ではない。
- 新しい日本語通知を含む静的フォントの強制再生成も確認。一時TMPフォントを破棄する前にAtlas・Materialの所有権を移し、保存済み資産の破棄を試みるエラーを修正した。
