# エンジンサウンド検証

実装と再実行手順： [Documentation/EngineAudio.md](../../Documentation/EngineAudio.md)

- `01-idle.wav`：アイドリング。
- `02-acceleration-tunnel-braking.wav`：6速まで加速、トンネル、減速を含む30秒の合成サンプル。
- `03-open-road.wav` / `04-tunnel.wav`：同じ5,200 rpm・同じ負荷で屋外とトンネルを比較。
- `05-gameplay-launch.wav` / `06-gameplay-tunnel.wav` / `07-gameplay-exit.wav`：Unity実走行中のDSPコールバックから採取したPCM（ネイティブ出力前）。
- `drive.csv`：30秒サンプルの速度・負荷・ギア・回転数・トンネル入力。
- `gameplay.csv`：実車位置・速度・ギア・回転数・トンネル判定。
- `analysis.json`：WAV解析とシフトアップ時の回転落ち。
- `performance.txt`：Unity Editorでの4台分のDSP時間とGC測定。
- `gameplay-result.txt` / `gameplay-tunnel.png`：実走行の検証結果と実画面。

サンプルの音量は正規化していません。同じ出力音量で比較できます。

## 2026-10-17 検証結果

Unity 6000.3.9f1でオフライン検証と実走行録音を実行。再現可能な加速シーケンスで1〜6速、実コースの自動運転では最高5速まで確認しました。実走行の3,428フレーム（ゲーム時刻3.003〜80.049秒）を保存しています。

- 発進13.978秒・トンネル内12.000秒・出口4.000秒を44.1kHzステレオで実録音。全WAVでクリッピング0。
- 実トンネル内判定0.77〜1.00。出口での左右差RMSは最初の0.5秒0.01815から最後の0.5秒0.00000036へ減衰。
- 44.1／48／96kHz、コールバック分割によるPCM完全一致、エンジンミュート、残響減衰、GCゼロ、既存のP1／P2出力・ModernUI検証を通過。
- サンプルを解析して、変速速度域、歪み後のDC除去、トンネルの音圧、サンプルレートに依存しない残響ダンピングを改善しました。実スピーカーの周波数特性を使った聴感調整は含みません。

この作業ツリーではモデルとフォントがLFSポインターだったため、ローカルキャッシュから展開しました。検証時のみチューブFBXの自動LOD生成を無効にし、検証後にインポーター設定を復元しています。Play Mode起動時に既存のUnity Searchインデックス例外と負のスケールのBoxCollider警告が出ましたが、録音・走行・ギア照合は完了しています。カメラ画像は走行ビューで、HUD文字列は実UIコンポーネントから別途照合しています。
