# エンジンサウンド検証

実装と再実行手順： [Documentation/EngineAudio.md](../../Documentation/EngineAudio.md)

- `01-idle.wav`：アイドリング。
- `02-acceleration-tunnel-braking.wav`：5速まで加速、トンネル、減速を含む30秒の合成サンプル。
- `03-open-road.wav` / `04-tunnel.wav`：同じ5,200 rpm・同じ負荷で屋外とトンネルを比較。
- `05-gameplay-launch.wav` / `06-gameplay-tunnel.wav` / `07-gameplay-exit.wav`：Unity実走行中のDSPコールバックから採取したPCM（ネイティブ出力前）。
- `drive.csv`：30秒サンプルの速度・負荷・ギア・回転数・トンネル入力。
- `gameplay.csv`：実車位置・速度・ギア・回転数・トンネル判定。
- `analysis.json`：WAV解析とシフトアップ時の回転落ち。
- `performance.txt`：Unity Editorでの4台分のDSP時間とGC測定。
- `gameplay-result.txt` / `gameplay-tunnel.png`：実走行の検証結果と実画面。

サンプルの音量は正規化していません。同じ出力音量で比較できます。

## 2026-10-17 レーシング向け変速調整後の検証結果

最終減速比を7.4から4.1へ変更し、全開シフトアップ速度を約32／47／64／85／111 km/hから約61／88／121／161／210 km/hへ延長しました。部分アクセルでも7,500〜7,600 rpmを使い、アクセルオフだけではシフトアップしません。

Unity 6000.3.9f1で55 km/hの1速、80 km/hの2速、110 km/hの3速保持、アクセルオフ保持、高速域での6速到達と既存の音声・HUD回帰検証を通過。実コースの最高速は約86.8 km/hで、最高2速を使用しました。走行記録は7,312フレーム、ゲーム時刻3.000〜80.029秒です。

約77 km/hの走行区間では、従来の中央値5速から2速へ変わり、回転数中央値は約6669 rpmです。詳細は `gear-comparison.json` を参照してください。30秒のサンプルは約166 km/hまで5速を使い、実走行録音3本も更新しました。

44.1／48／96kHz、コールバック分割によるPCM一致、ミュート、トンネル判定と残響減衰、GCゼロ、既存のP1／P2出力・ModernUI検証を通過。全WAVのクリッピング・DC・実出口の残響減衰は `analysis.json` に保存しています。実スピーカーの周波数特性を使った聴感調整は含みません。

検証時のみチューブFBXの自動LOD生成を無効にし、検証後に設定を復元しています。Play Mode起動時に既存のUnity Searchインデックス例外と負のスケールのBoxCollider警告が出ましたが、録音・走行・ギア照合は完了しています。カメラ画像は走行ビューで、HUD文字列は実UIコンポーネントから別途照合しています。
