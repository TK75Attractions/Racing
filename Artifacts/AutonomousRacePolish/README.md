## データ

- `before-drive.json`：表示改善前の高速／初心者対上級／接続断の3条件。復帰ボタン・完了音と試走用の検査条件の修正後に測定。記録のrevisionは起動時HEADを示し、最初の起動時に未コミットだった試走用修正を含む。
- `after-drive.json`：表示改善後の同じ3条件と、追加のアイテムあり条件。
- `comparison.csv`：両者の完走・進捗・復帰・逸脱の比較。全データは上記JSONに保持。
- `barrier-coverage.json`：衝突面のカバーと4条件の封じ込め検証。
- `verification.json`：NUnitの件数・成否と、Editor／Play Mode検証の成功マーカー。

| 高速 P1 | 完走→完走 | 3,808→3,808 | 0→0 |
| 高速 P2 | 完走→完走 | 3,808→3,808 | 0→0 |
| 初心者対上級 P1 | 未完走→未完走 | 171→3,407 | 43→0 |
| 初心者対上級 P2 | 完走→完走 | 3,808→3,808 | 0→0 |
| 接続断から復帰 P1 | 完走→完走 | 3,808→3,808 | 0→0 |
| 接続断から復帰 P2 | 完走→完走 | 3,808→3,808 | 0→0 |
| アイテムあり P1 | —→完走 | —→3,808 | —→0 |
| アイテムあり P2 | —→完走 | —→3,808 | —→1 |

試走エージェントは画面の案内を理解することを仮定している。とくに初心者モデルの値には案内を参照する経路の修正も含むため、人間の上達や楽しさの改善率とは解釈しない。CPUは人間2名が完走した時点でレースが終わる既存ルールに従うため、ゴール直前でも未完走になる場合がある。
