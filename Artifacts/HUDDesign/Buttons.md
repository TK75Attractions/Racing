# Neon button interaction guide

添付の「ゲージ付きボタン」「ボタン（改良版）」を基準に、Unityの共通ボタンを更新しました。

[状態一覧のUnityプレビュー](hud-button-guide-1920x1080.png) / [スタート準備完了のプレビュー](hud-title-ready-1920x1080.png)

## 色と形

| 用途 | 配色・表示 |
| --- | --- |
| 主アクション | ピンクのグラデーション、角を切った二重枠、ダブルシェブロン |
| 戻る・設定など | 濃紺とブルー／シアンの発光枠 |
| 終了・中断 | レッド。誤操作を避ける長押しゲージ |
| スタート確定後 | ゴールドの枠と満タンゲージを保持 |
| 無効 | グレー、発光なし、ホバー／押下に反応しない |

## 状態とアニメーション

- **選択／ホバー**: 軽い跳ね返り、明るくなる枠、左から右へ走る光、シェブロンの移動。
- **押下**: ボタン本体が沈み込み、内側の影が強くなる。文字とアイコンも少し下へ動き、外側の発光を抑える。
- **チャージ**: 黒いトラック内の5セグメントとパーセント表示が、確定までの経過時間に連動。
- **MAX／確定**: 明るい発光と短いスパーク。確定前の短いタップや途中で外へ移動した操作はキャンセル。
- **スタート待機**: 確定後に指／ペダルを離してもゴールドと100%を保持。画面を閉じるとリセット。

## 適用範囲

- タイトル: スタートと終了に長押しゲージ。車の選択・設定・遊び方は通常ボタンのホバー／押し込み。
- リザルト: 4項目すべてに長押しゲージ。リトライはスタート系のゴールド状態。
- 中断メニュー: 再スタートはピンク、走行方向の変更はブルー、中断はレッドの長押し。
- 車／コース確認・設定・遊び方のシート: 同じ配色、枠、ホバー、押し込みを使用。

ポインターはスタート・終了／中断を0.65秒、リザルトを1秒長押しで確定。ゲージ付きボタンはキーボードの決定キーでも保持でき、ペダルは既存のゲーム側の確定時間に合わせて進捗を表示します。

## 軽量化と検証

ポインターとペダルで同じアニメーション担当を使用し、同じボタンを2つのスクリプトが同時に動かさないようにしました。光の走査・跳ね返り・スパークは短時間で収束し、状態が止まれば再描画も停止します。ゲージとパーセントは変化したときだけ更新します。

- 50%チャージ表示と、入力を離した後のスタート100%保持を検証。
- アニメーション収束後の120フレームで、枠・ゲージ・エフェクトの再生成0回、追加メモリ確保0バイト。
- 実際のポインターイベントで、短押しキャンセル・長押し1回確定・無効時の入力拒否を検証。
- 2人対戦の開始、ゴール、リザルト、リトライ、各メニューの画面遷移を検証。
- Unityで各状態と画面を描画し、日本語と文字の欠け／はみ出しを検査。
