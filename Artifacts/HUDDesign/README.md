## デザインと操作

ボタンは追加の添付ガイドを基準に、発光・押し込み・長押しゲージ・ゴールドの待機状態を共通化しました。[ボタン仕様と検証](Buttons.md)。

- 主ボタン・自分の順位行: `#FF0663` のピンク、発光枠、左右で濃さを変えたグラデーション。
- 通常ボタン・パネル: 濃紺の半透明面、`#04C7FF` のシアン枠、角のカットと斜めのアクセント。終了ボタンは暗いピンク。
- 日本語と英語を併記。日本語にはM PLUS 1の静的Medium / Boldアトラスを使用。
- スタートボタン・ペダルで各プレイヤーが準備完了になり、2人が揃うと開始。
- カウントダウンは5灯のランプ、分割した円形リング、大きな数字。レース開始前はコース情報とラップ数を表示。
- レースHUDは順位・ラップ・タイム・2人の順位表・実コースのマップ・速度・加速残り時間を表示。ペダルとハンドルのバーは実入力に連動。
- リザルトは実データの順位・タイム・ギャップ、ベスト／最終ラップ、1位の金／2位の銀メダル。未完走はDNFとして表示。
- 下部4ボタンはリトライ、車の確認、コースの確認、メインメニュー。ハンドル操作でも4項目を順番に選択できる。

参考画像の8台表示は、現在のゲームの2人対戦に合わせています。車とコースは現在のゲームに入っている1種類を確認・決定する画面です。参考画像のTCS／ABS欄には、実際に操作するペダル／ハンドル情報を配置しました。

## 主な実装

- `Assets/Managers/UI/NeonUI.cs`: 共通部品・配色・英日メニュー。
- `RacingPanelGraphic.cs` / `RacingIconGraphic.cs`: Canvas解像度に合わせて描画する形・枠・アイコン。
- `ScreenTransitionController.cs` / `NeonTitleMenu.cs`: タイトル、カウントダウン、各メニュー。
- `RacingHUDBuilder.cs`: レース中のレイアウトとデータの表示ノード。
- `RacingLeaderboardUI.cs` / `RacingTelemetryUI.cs`: 実データ・実入力。
- `ResultUIManager.cs`: 実際のレース結果と4つの操作。
- `RacingHUDFontBuilder.cs`: 表示する文字からフォントを再生成。既存アセットのGUIDを維持。
- `RacingHUDDesignPreview.cs`: 実UIのプレビューを書き出し、文字欠け・はみ出しを検査。

## 負荷対策

後方ミラーと専用カメラを削除し、未使用ブースト・不変のボタン・順位表の再生成を停止。順位表の二重更新を一本化し、速度計・ブースト・順位表を独立したCanvasにしてタイマー更新による再バッチを抑えています。[原因と検証記録](Performance.md)。

さらに、速度計は点灯する目盛りが変わる時だけ更新し、ブーストの固定部分と残量の弧を分離。タイム・速度・残量は数値バッファで表示し、毎フレームの文字列生成を省いています。色・形・レイアウト・表示精度を維持した軽量化です。

## 検証

`RacingHUDDesignPreview.RunBatch` でリソース、データの結び付け、日本語、クリック対象、音の切り替え、DNF表示、マップの位置・追従、文字のはみ出しを検証。1080pの各画面と720p／4KのレースHUDを描画します。

`MultiplayerPlayModeValidation.RunBatch` は2画面での開始、カウントダウン、ゴール、観戦、共通リザルト、リトライ、車／コース確認への復帰、メインメニューへの復帰を確認します。

## 現在のメニュー構成

タイトル画面は「はじめる」の1ボタン、リザルト画面は「もう一度」「メインメニュー」の2ボタンです。車／コース確認への導線は表示しません。
