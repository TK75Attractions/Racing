# 坂道カメラ・チューブ側面の修正確認

2026-10-16、Unity 6000.3.9f1で検証。

- `SlopeTubeDrivingValidation.Run`：平地と左右60／80／90度の計7面で、10 m/sから1秒間アクセルを入れた速度はすべて28.127 m/s。全輪の接地を維持。ドリフト補正後は20.000 m/sを維持し、路面法線方向への速度・路面外の回転を増やさないことを確認。
- マーカーのない80／90度の壁では接地を拒否。重力を無効にした平面上での比較で、加速比較時だけ姿勢を固定しています。実際の円筒内壁で重力・遠心力を含めた側面走行の連続試験ではありません。
- ±20度の坂と平地でカメラの上下角が路面に追従。坂に沿った移動、上下振動、ジャンプ中の車体回転、リスポーンを確認。既存のカメラ振動テストは±0.12 mの入力に対して最大偏差0.0029 m。操舵・ドリフト・視覚効果の既存回帰検証も通過。
- `TubeCourseValidation.Run`：実シーンでチューブ内壁の走行面マーカーを確認。道路の折り返し・床との交差・チューブ障害は0。道路形状は変更していません。
- `TubeGameplayCapture.RunBatch`：実際のP1/P2車両を自動入力で走らせ、両車が約1.83 kmの一周、ジャンプ・着地を完了。壁接触0件。P1の全輪離陸は0.60秒、P2は0.70秒。実車の位置や速度を走行中に補正せず、中央付近のレーンを走行しています。

`Gameplay` に実際のP1カメラの4枚、`Playthrough/report.json` と `trace.csv` に走行結果、`geometry.json` に道路形状の検証結果を保存しています。`unity.log`、`course.log`、`gameplay.log` はローカルに保存され、Gitの対象外です。Play Mode開始時にはUnity Searchの既存インデックス起動エラーが出ましたが、周回・撮影は完了しています。

モデル読み込み時のLOD生成が長時間かかったため、この検証では一時的にチューブFBXの `generateMeshLods` を無効にしました。検証後にインポーター、Unityが更新した道路マテリアルとフォントキャッシュを元へ戻しています。シーンとFBX本体に差分はありません。

再実行方法と実装の詳細は [Documentation/SlopeCameraAndTubeDriving.md](../../Documentation/SlopeCameraAndTubeDriving.md) を参照。
