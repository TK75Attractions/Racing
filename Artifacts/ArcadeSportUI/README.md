## 確認内容

- EditMode: 166 / 166 件成功（最新mainを統合して再実行）。
- 実車選択: P2 先行、長押し決定、練習との並行、車種・性能・固定プレイヤー色の引継ぎ、練習の時間切れ、レース開始まで成功。
- 実レース: 加速、カウントダウン、ゴール、観戦、実リプレイ、結果、リトライ、各自のタイトル復帰、両者中断、ゴール演出中の中断・時間切れを確認。
- 終了画面: 描画後の P1/P2 撮影、踏みっぱなし防止、相手の結果を残したまま個別にタイトルへ戻る動作を確認。
- 見た目: 透過ロゴ、メーターの透け、タイム下の短い通知、ボタンの目盛り・斜線、文字欠け、重なりを画像で確認。

今回の追加確認: 台座と車の同時回転、台座への接地、過去の保存色を無視したP1/P2固定色、色選択UIの撤去、日次順位のみの表示、速度指針の色変化、ExtraBold、右下影、縮小率0.5から等倍への復帰。4Kの実機フレーム時間は未計測です。

2026-10-26 の追加確認: 両メーターのサイズ一致、周回バーの1→2→1リセット、順位の背景、通知の消去と拡大しない表示、右端での接近・効果・メーターとの重なりを検証。実シーンではシールド発動イベントと残り時間の描画、パネルを隠してもデバッグ入力が維持されることを確認。720p・1080p・4Kを再出力。車選択・終了画面の単独検証は前回の結果です。

中央カード生成を廃止し、ドリフト・ジャンプ・入力再開等の案内をタイム下の通知へ統一。最新mainの通知優先度・接続と再開・ポーズと終了時の消去を維持して再検証しました。
