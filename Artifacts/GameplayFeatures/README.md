# 第1段階の機能拡張・検証記録

2026年10月19日、Unity 6000.3.9f1、製品コード `be51557` を含む作業ツリーで確認。

## 確認できたこと

- `core-tests.txt`：既存の入力・レースセッションに、プリセット固定／予約、被弾時間の上限、追走蓄積を加えた70テストが成功。
- `unity-validation.txt`：実際の接地問い合わせを使い、追走成立、即時OFF、上下別路面、遮蔽物、切断、逆走を検証。ドリフト成功通知、被弾の重複禁止、OFFでの従来動作への復帰、復帰保護の維持、日本語フォントも確認。
- `feature-toggles.json`：実コースの走行中にF8でパネルを開き、全OFF→やさしいアイテム→元のスイッチへ復元。次レースのプリセットを予約しても現在の周回数は変わらない。3段階の検証が成功。

| 条件 | 周回 | P1 | P2 | 終了時のレース時計 | 試走中の例外 |
|---|---:|---|---|---:|---:|
| Standard、アイテムなし、走行中の切替あり | 2 | 完走 | 完走 | 197.98秒 | 0 |
| Experience、アイテムあり | 1 | 完走 | 完走 | 102.74秒 | 0 |

2条件とも、実際の学校モデルと長さ1904.19mのコース上で、P1/P2とCPU2台を入力経由で走らせた。車両の位置・速度・周回数・完走結果は強制設定していない。CPUは人間2人の完走時点で終了するため、この記録でCPUがDNFになることは終了仕様どおり。

## 評価の限界

既知コースを走る自動入力、3倍速での確認である。初見者の理解度、実ハンドルの入力遅延、実モニター2枚と音声機器の組合せ、楽しさ・公平感は未評価。

Standardの自動運転ではドリフト解放1回を記録したが、追走加速は0回だった。固定レーンの入力モデルは追走成立を狙わない。追走の正の成立は専用の接地・幾何検証で確認しており、実コースでの発動頻度・体感の採用判断とは区別する。

ESP32を接続せずに起動したため、試走開始前にシリアルポート未接続の初期化エラーがある。上表の「試走中の例外」は試走エージェントが記録した期間を指す。実機のセンサー校正・再接続試験の代替にはならない。

`standard.json`の`revision`は起動時のベース`f28b1cd`。その実行は後の`be51557`に保存した製品変更を含む作業ツリーで行った。`experience.json`のベースは`be51557`で、Editor専用のプリセット指定を追加した作業ツリー。異なる周回・アイテム条件のため、2条件の時間を速さの改善率として比較しない。
