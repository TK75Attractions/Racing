# USBで管理画面を使う

iPhone / iPadの専用アプリ「Racing USB」を使い、データ通信対応のUSBケーブル1本でMacへ接続します。インターネット共有・接続コードは不要です。

初回のインストール、通信経路、日常の使い方は[専用アプリの手順](DashboardIPhone.md)を参照してください。無線から利用するときは[Tailscaleの手順](DashboardStartup.md)を使います。

## 起動

自動起動対応のMac版RACEは、管理中継とUSB補助アプリも起動します。ゲーム停止中に手動で準備する場合は、通常の管理中継を起動し、`Tools/DashboardUsb/Start USB Dashboard.command` を開いてください。`Start iPhone USB Dashboard.command` も同じ方式で起動します。

端末をロック解除してアプリを開くと自動接続します。準備状況はMacの `http://127.0.0.1:8767/` で確認できます。ゲーム停止中も管理画面の「ゲーム設定 → ゲームの更新」から最新mainを取得し、ビルド・起動できます。詳細は[更新手順](OperatorUpdate.md)を参照してください。

## 接続できない場合

- 接続待機のまま: データ対応ケーブル、端末のロック解除、Macの信頼、最新版アプリを確認します。
- 管理画面を開けない: 通常の管理中継が8766番で起動しているか確認します。
- Unity未接続: ゲーム停止中は通常の表示です。ゲームの更新ボタンは独立して利用できます。映像とゲーム操作は起動後に利用できます。

`sh Tools/DashboardUsb/test.sh` は専用アプリのSwift通信部品とMac中継を一時ポート・偽USBで検証し、管理画面のUIテストも実行します。実際のUSB遅延やiPad実機での動作確認を代替するものではありません。
