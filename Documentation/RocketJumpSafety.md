# Rocketとジャンプ

Rocketは最高240km/h（66.67m/s）、加速度45m/s²で自動走行します。コース進行方向の90m先までジャンプを先読みし、踏切の18m手前までに水平速度を22m/sへ落とします。接近中の速度上限は減速度65m/s²による制動距離から計算します。上向きの速度は水平速度と同じ割合で抑え、落下速度は変更しません。

着地点の60m後方まで空白区間を確認しますが、速度制限を残すのは車が空中にいる間だけです。接地はロケット中も毎物理フレーム、車輪の実レイで確認します。タイヤ力の処理を省く自動走行中の古い接地フラグは使いません。着地後の取得や再加速が約79km/hで止まり続ける不具合を解消しています。効果が飛行中に終了しても保護は残り、着地したら解除します。

通常走行では、ジャンプ手前38m以内で正面を向いた接地中の人間の車へ、22m/sを目指す穏やかな助走加速を加えます。ハンドル操作はそのまま使えます。操作待ち・切断・復帰直後・妨害中・逆向き・明示的な後退入力では働きません。CPUは従来のジャンプ間隔と速度判断を維持します。

P2のリセットはJIS配列のMacにもある `/` キーです。Right Ctrlも互換キーとして使えます。P1はSpaceで、両者ともESP32操作時にも利用できます。

チューブでは既存の内壁Colliderと道路の各断面の交点を求め、道路端から壁まで同じ舗装を生成します。隙間の再発を避けるため壁へ5cm重ね、走行可能なMeshColliderも付けます。ジャンプの空白区間には生成しません。

検証・録画: SampleSceneを開いて `Racing > Validate Rocket Jump Fix And Record` を実行します。入力制御による実際のPlay Mode走行で、試験用ItemBoxの抽選だけをRocketに固定します。結果・物理ログ・録画フレームは `Artifacts/RocketJumpFix` に出力します。
