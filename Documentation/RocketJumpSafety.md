# Rocketとジャンプ

Rocketはコースの進行方向に沿って90m先まで路面のないジャンプ区間を先読みし、踏切の18m手前までに水平速度を22m/sへ落とします。接近中の速度上限は減速度65m/s²を使った制動距離から計算します。減速時は坂で生じた上向きの速度も同じ割合で抑え、落下速度は変更しません。

踏切を通過した後も60mの着地後区間で制限を保ちます。Rocketの効果が空中で終了してもこの保護は残り、着地後に急に再加速して曲がり損なうことを防ぎます。通常のジャンプでは従来の空中慣性を使います。

P2のリセットはJIS配列のMacにもある `/` キーです。Right Ctrlも互換キーとして使えます。P1はSpaceで、両者ともESP32操作時にも利用できます。

チューブでは既存の内壁Colliderと道路の各断面の交点を求め、道路端から壁まで同じ舗装を生成します。隙間の再発を避けるため壁へ5cm重ね、走行可能なMeshColliderも付けます。ジャンプの空白区間には生成しません。

検証・録画: SampleSceneを開いて `Racing > Validate Rocket Jump Fix And Record` を実行します。入力制御による実際のPlay Mode走行で、試験用ItemBoxの抽選だけをRocketに固定します。結果・物理ログ・録画フレームは `Artifacts/RocketJumpFix` に出力します。
