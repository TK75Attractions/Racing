# 本日のランキング

このゲームを実行する端末で、その日に完走した人間プレイヤーの総走行タイムを集計します。名前や個人IDの登録はないため、同じ人が再プレイした場合も別の記録です。各記録は「第○レース P1／P2」で識別します。ネットワークやFirebaseの接続は不要で、他の端末との合算は行いません。

## 順位と対象

- CPU、未完走、無効なタイム、規定周回数に達していない記録は対象外。
- P2自動運転を一度でも使った走行、P1のConstant pedalをレース中に一度でも使った走行は対象外。人がペダルを操作するキーボード／W/Sモードは対象。
- 自動バッチ試験とエディターのBalancePlaytestAgentによる試走は本番履歴に登録しない。
- 速い総走行タイムから順位を付ける。比較は結果画面に表示するミリ秒単位で、同タイムは同順位（1位・1位・3位）。
- コース形状、周回数、正走／逆走、標準／体験が一致する記録を比較する。車種は共通のランキングに含める。
- 同一レースのP1／P2は同じレース番号。結果画面の再表示や完走通知の重複では追加登録しない。

## 表示

結果画面の右側に上位5件を表示し、今回の記録は色と「今回」の文字で示します。各ディスプレイの下段にはそのプレイヤーの順位を表示するため、上位5件に入らなくても自分の順位が分かります。レース内の順位・総タイム・ラップタイムも引き続き表示します。

F8の `Today ranking panel` はランキングの表示だけをON／OFFします。OFF中も対象となる完走記録は保存します。

## 日付・保存

完走した時点の端末のローカル日付（0:00切り替え）を使います。日付をまたいでP1／P2が完走した場合はそれぞれの完走日の記録になります。結果画面を表示したまま日付が変わった場合も、新しい日のランキングへ切り替えます。前日に完走した自分の記録にはその旨を表示します。

保存先は `Application.persistentDataPath/DailyRankings/yyyy-MM-dd.json`。完走通知が正式に登録された直後に保存するため、相手のゴールや結果画面を待たずに記録が残ります。日付別ファイルを保持し、再起動後は当日分を読み直します。

一時ファイルを書き終えてからファイルを置き換え、直前の正常なファイルは `.bak` に残します。読み込み失敗時はバックアップを試し、両方読めない場合は元ファイルを上書きせず画面で知らせます。書き込み失敗時は今回の記録をメモリに保持し、再起動で消える旨を表示します。運営が履歴を回収する際は、このフォルダをコピーしてください。

コースの識別は64点の中心線・幅とシーン、周回数・走行方向・プリセットをハッシュ化します。走行物理を大きく変更し、以前の記録と比較できなくなった場合は `DailyRaceRanking.BoardKey` の `rules-v1` を更新してください。

## 検証

`Tools/Validate-Rgp.sh` で順位・同着・参加条件・日付・重複・上位外の順位を検証します。Unityの `Racing > Validation > Today Ranking` は一時フォルダだけを使って、再起動・日付変更・保存失敗・バックアップ復旧と結果画面の720p/1080p描画を確認します。

実コースの統合試験は `RACING_DAILY_RANKING_CHECK=1` を付けて人間相当の入力ボットで2周走行します。この試験だけは専用履歴へ登録を許可し、本番の完走コールバック・P1/P2の結果画面・再読み込みを確認します。本番履歴やネットワークへの書き込みは行いません。記録は [DailyRanking](../Artifacts/DailyRanking/README.md) を参照してください。
