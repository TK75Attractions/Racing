# 説明一覧・練習ガードレール・トンネル加速

練習後の説明は、ジャンプ／加速パネル／光る箱／すべった時の操作の4項目を、写真とふりがな付きで2列×2段の1画面に表示する。8秒後に自動で進み、4秒後からペダルを離して踏み直すと進める。両プレイヤーは独立して読む。準備全体の制限は変更しない。

練習コースの左ガードレールは、右側と同じ三角形の向きで生成していたため、道路に面する側と上面が裏を向いていた。左側の面を反転し、道路側から見え、衝突する向きに修正。両端もふさぎ、アスファルトをレールの下へ8cm重ねる。車輪が走る床は従来の単一の平坦なColliderを維持し、新しい段差や継ぎ目を作らない。

トンネル内の加速パネルは、瞬間速度+10m/s、追加加速度24m/s²、継続3秒へ強化（従来は+4m/s、10m/s²、1.25秒）。通常の抵抗、操舵時の減速、入力断・復帰時の解除は従来どおり。3秒は追加加速の持続時間であり、終了後に強制的に速度を戻すことはしない。
