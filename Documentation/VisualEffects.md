# 画質と走行演出

## 車の動きの表示（バックログ12・20・21・22）

プレイヤー車とCPU車には `CarNightGlow` が接地中の柔らかい影を描きます。影は同じ車体寸法の放射状マスクを使い、発光板より先の透明描画順に置きます。影専用ライトやカメラ別エフェクトは追加していません。

`TireForce` は物理のタイヤ位置・接地判定を変えず、子の表示メッシュだけにサスペンションの接地補正と車輪回転を適用します。操舵角は従来どおり前輪の表示にも同じ符号で反映します。回転は高速域で毎秒36 radに上限を設け、固定更新での逆回転風のちらつきを抑えます。`CarBodyMotion` は表示専用の車体枝へ最大1.6度のピッチ、2度のロールと1.8 cmの揺れを加え、着地時は最大0.7度だけ短く沈みます。車体剛体・タイヤ・カメラには適用しません。

Unity での車輪接地、操舵方向、影の重なり、着地の見え方は未確認です。リードは `CourseVisualTour` で停止・加減速・左右旋回・ジャンプ着地を撮影し、2画面で描画負荷も確認してください。

## 高速・ブースト中の中央視界（2026-10-21、バックログ28）

`RaceSpeedVisualController`のFOVは通常60度／高速68度、ブースト加算3度・開始キック2度、上限74度。引きは高速0.6 m＋ブースト0.15 mです。速度線は実カメラ前方のFOV・画面比率に合わせた外周の楕円帯から発生し、伸張係数を0.20→0.06へ短縮。描画直前にも線の両端を含め中央の楕円（Viewport半径0.32×0.30）へ入る粒子を除きます。各プレイヤーの速度線は専用カメラだけに描画します。

雷は中央の矩形（半径0.22×0.24＋線幅／Bloom余白0.03）を横切る幹・枝をカメラごとに非表示にし、描画後に戻します。ドリフト解放の雷は車幅外1.2 mへ離し、前方長3.5 m・枝なしに変更。解放／追い抜き／最終周の画面フラッシュ既定値を0.12／0.12／0.20へ抑え、最終周の落雷は左右24 mへ離します。花びらは各カメラの前方4 m未満と、35 m以内の中央楕円（半径0.30×0.30）から描画前に除き、既存粒子の流入も防ぎます。範囲はInspectorで調整できます。

シーン・Prefabに保存された旧既定値は初回有効化時に一致する項目だけ移行し、他の調整値を保持します。Unityでの描画・負荷確認は未実施。リードは`CourseVisualTour`の同一定点とP1/P2の180 km/h実走で、ブースト・満チャージ・解放・追い抜き・最終周が重なる場面の中央視界と、花びら除去／雷の消え方を比較してください。API参照：[SphereCastNonAlloc](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/Physics.SphereCastNonAlloc.html)、[カメラ描画前コールバック](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/Rendering.RenderPipelineManager-beginCameraRendering.html)。

## 車体の参加者バッジ

レース中の P1／P2／CPU は、`CarParticipantBadge` が車体上に形状付きの発光札（1P／2P／CPU）を表示します。文字は実行時生成のビットマップで、フォント資産を必要としません。P1／P2 の札は自分側の表示カメラでのみ非表示となり、CPU の札は両画面に表示されます。近距離では薄く、遠距離では最大 2.5 倍まで拡大します。

走行中の見た目を支える描画設定と、タイヤ・衝突の演出をまとめます。いずれも表示専用で、車の物理挙動や判定は変更しません。

## 描画の基本設定

- **トーンマッピング**：`Assets/Scenes/SampleScene/VManager Profile.asset` に `Tonemapping`（Neutral）を入れています。HDR の明るい光（ネオン、ランプ、桜の発光）が白く飛ばず、Bloom が滑らかに滲みます。ACES はコントラストが強くなる一方で、ネオンの青やピンクの色味がずれるため採用していません。
- **HDR カラーグレーディング**：`Assets/Settings/PC_RPAsset.asset` の `Grading Mode` を High Dynamic Range にしています。トーンマッピングが白飛び前の値を受け取れるようにするためです。
- **アンチエイリアス**：`SampleScene` の `BackImageCamera` に SMAA（High）を設定しています。URP のカメラスタックでは、アンチエイリアスは Base カメラの設定がスタック全体（`MainCamera` などの Overlay を含む）に使われます。そのため Overlay の `MainCamera` 側で設定しても効きません。2 人目の画面は `CManager` を複製して作るので、同じ設定になります。TAA は Overlay カメラを重ねる構成では使えません。

## 夜の縁日ネオン化（第 1 段）

`NightEnnichiVisualBuilder` が次の変更をアセットと `SampleScene` に保存します。再実行しても同じ割り当て・設定になります。

- 校舎 FBX の木 15 本は、LOD0 のサブメッシュの三角形数が多い方を葉、少ない方を幹として、桜色の弱い発光とこげ茶に変更します。既存の LOD と `meshLodSelectionBias` は維持します。
- `TubeInterior.mat` を暗い紺・Smoothness 0.55 にし、FBX の `地下チューブ` も同じマテリアルへ remap します。
- シーンの `VManager` の `speedMotionBlurLow` / `speedMotionBlurHigh` / `boostMotionBlur` を 0 にします。コード既定値も 0 です。速度感は既存の FOV 変化とスピードラインで表現し、ブーストの色収差・歪み・露出などは維持します。
- `RaceEnvironment` を夜（1）・晴れ（0）に設定します。照明と空は再生時に既存コントローラーが反映します。
- ガラス系 6 マテリアルを、不透明の暖色発光による窓明かりへ remap します。

木・窓の新規 URP/Lit マテリアルは `Assets/Art/NightEnnichi/` に作ります。FBX の割り当ては `ModelImporter.AddRemap` → `SaveAndReimport` で行い、シーンの Renderer 上書きは追加しません。

実行は Unity メニューの `Racing > Visual > Apply Night Ennichi Look`、または Unity 6000.3.9f1 で次を使用します（`<project-path>` はプロジェクトの絶対パス）。メニュー実行時は先に `SampleScene` の編集中の変更を保存してください。

```text
Unity -batchmode -nographics -projectPath "<project-path>" -executeMethod NightEnnichiVisualBuilder.Run -quit -logFile "NightEnnichi.log"
```

成功時は `[NightEnnichi]` の要約 5 行を出力します。必要なアセット・木の構造・コンポーネントなどが見つからない場合は例外で失敗します。適用後の画面確認は Game ビューで行ってください。

## タイヤ痕とタイヤスモーク

`Gmanager` がレース開始時に各車へ `TireEffectsVisual` を追加します。タイヤごとに滑りの強さ（0〜1）を求め、一定以上で路面に痕を残し、白煙を出します。

- **ドリフト後の直進**：ドリフトチャージが残っていても、それだけでは痕を出しません。実際のタイヤの横滑りが収まると痕と煙の発生を止めます。
- **急ブレーキ**：ペダル -0.5 以下かつ前進 8 m/s 以上で、全輪から痕が出ます。後退中は出ません。
- **横滑り**：タイヤの横滑りの速さが 3 m/s から出始め、9 m/s で最大になります。
- 3 m/s 未満の低速と、接地していないタイヤでは出ません。

痕は `TireMarkRenderer` が全車分を 1 つの動的メッシュにまとめて描きます。初期設定では 4096 区間まで残り、超えると古い痕から上書きします。両者の完走やタイムアウトでレース全体が終了した時に消え、レースの開始時とタイトルへ戻る時にも消去します。1位だけが完走し、2位が走行中の間は残ります。リスポーンなどで 3 m 以上瞬間移動したときは、離れた点どうしを繋ぎません。

煙は環境光と太陽光の色で照らされるので、夜は暗く、昼は明るく見えます。

調整は車の Inspector の `TireEffectsVisual` で行います（実行時に追加されるため、Prefab に先に付けておくとその値が使われます）。痕の色と上限区間数は `TireMarks` オブジェクトの `TireMarkRenderer` で変更できます。

## 衝突の火花とカメラの揺れ

`CarCollisionSparks` は車同士の接触に加えて、建物やバリアなど動かない物体をこすったときにも火花を出します。

- 接触法線の Y が 0.65 以下を壁として扱い、地面との接触では出しません。
- こする速さが 3 m/s 未満では出しません。

衝突の瞬間には、強さを `Impact` イベントで通知します。`Gmanager` はそれを、その車を操作しているプレイヤーの `RaceSpeedVisualController.AddImpact` に繋ぎ、そのプレイヤーのカメラだけを短く揺らします。

- 車同士では相対速度、壁では壁に垂直な速さを使います。2 m/s 未満では揺らさず、15 m/s で最大になります。
- 正面衝突は強く、壁をかすめるだけなら弱く揺れます。
- 揺れは強さの 2 乗で効き、0.35 秒で収まります。
- 強さや時間は `RaceSpeedVisualController > Impact Shake` で調整できます。

同じ `Camera Shake` 欄の `Boost Shake Rotation` は、ブースト中の回転の揺れ（度）です。以前は位置用の値を誤って流用していたため、独立した設定にしました。

## 確認

Unity メニューの `Racing > Validate Visual Effects` は次を検証します。

- トーンマッピング、HDR グレーディング、スタックの Base カメラの SMAA
- ブーストの回転の揺れが専用設定に従うこと
- 衝突の揺れの受け付け・上限・解除
- 壁と地面の判別と、衝突の強さの換算
- タイヤの滑りの判定（空中、低速、横滑り、ドリフト、ブレーキ、後退）
- タイヤ痕の追加・上書き・消去
- 専用シェーダーの読み込み

バッチ実行は `-batchmode -nographics -executeMethod VisualEffectsValidation.Run -quit` を使用します。

見た目の濃さや量は、Game ビューで昼と夜、晴れと雨を切り替えて実走し、調整してください。

## 安定した走行カメラ

通常走行・ブースト時の位置と回転のノイズは、`RaceSpeedVisualController > Camera Shake > Enable Driving Camera Shake` を標準で無効にしました。FOVと滑らかなプルバックは維持し、衝突時だけ短いインパクト演出を残します。

`RaceDirectionCameraController` は追従先の Rigidbody を Interpolate にし、車体の高さを 0.25 秒の SmoothDamp で追従・注視ターゲットへ共通適用します。水平移動は遅らせず、車体のピッチ・ロールをカメラへ伝えません。12 m 以上の瞬間移動では補間をリセットしてリスポーンへ即座に追従します。

`CarBodyMotion` は物理・タイヤを含まない描画用の車体ブランチだけを、速度に合わせて最大 0.018 m 上下させます。停車・空中・走行不可では滑らかに収まり、無効化時は元の位置へ戻ります。カメラは Rigidbody のルートを追うため、この演出は視点を揺らしません。練習モードも同じ車両とカメラ設定を使います。

`DrivingFeelValidation.RunBatch` で、±0.12 m の連続した上下振動の減衰、水平追従、水平なカメラ姿勢、リスポーン時の位置復帰、車体演出が物理やタイヤを含まないことを検証します。`RunFullBatch` は加えて実シーンの離陸・着地・姿勢回復と左右の走行を Play Mode で検証します（完了時に終了するため `-quit` は指定しません）。

2026-10-08、Unity 6000.3.9f1 の自動検証ではカメラ振動が最大 0.0029 m となり、17 通りの物理実走もすべて通りました。左右ドリフトの最大横滑りは 0.884 / 0.888 m/s、最大傾きはともに 0° でした。測定値と再実行方法は [DrivingFeel](../Artifacts/DrivingFeel/README.md) を参照してください。手動での運転感覚の評価は未実施です。
# 車のランプ（バックログ23）

尾灯は夜間・雨天時に弱い赤、実際のブレーキ入力中は強い赤、車体が後ろ向きに動いている間は白で表示します。正の加速入力では色を変えません。生成レンズは夜間にHDR値が1をわずかに超える設定で、Bloomを控えめに受けます。材質設定は **Racing > Visuals > Build Car Material Tuning** からクーペ・セダン・ホイールの素材へ適用します。
