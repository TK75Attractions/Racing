# はじめて遊ぶ人向けのアイテム改善

## 変更

- アイテム取得の説明が、同時に踏んだ加速床などのブースト通知で消えないよう修正。ロケットの自動操縦の説明も残し、コンフューズにはハンドル反転のアイコンを表示します。
- 取得時の案内を3.2秒、被弾・クリスタルを2.8秒にして、効果と対処を短い日本語で伝えます。再バインド時は以前のブースト状態を持ち越しません。
- 本番・練習の箱を、面取りした金色の縁、発光する「？」、青い回路模様、穏やかな明滅・脈動へ統一。128pxのミップ付きテクスチャを生成時に作り、毎フレームのピクセル更新・追加ライト・追加Colliderは使いません。見た目用のメッシュ・マテリアル・テクスチャは所有者が解放します。
- 練習中は「光る箱にふれよう／自動で発動するよ」と案内。練習を終えて停止している待ち時間には、シールド・ロケット・オイル・コンフューズ・青いクリスタルの一覧を表示します。運転中の走路と計器を一覧で隠しません。
- 練習の箱は固定18m先から、速度に応じた36～65m先へ配置。高速で練習を進めた場合にも、箱と案内を見る時間を確保します。コース終端190mの制限は維持します。完了直後の速度表示も停止状態へ同期します。
- 新しい日本語を既存の静的HUDフォント3種に追加。実行時の日本語フォント生成は追加しません。

抽選確率、各効果の強さ・持続時間、取得半径、復活時間、本番コース上の配置、CPUの走行ルールは変更していません。

## 検証方法

Unity 6000.3.9f1、最新main `1b170d6` を基点とした専用ブランチで検証します。

1. `-batchmode -executeMethod ItemFirstPlayCapture.Run -quit`：実際のアイテムイベントとHUDを使う表示回帰、箱の面・UV・生成リソースの再利用と解放、P1/P2各720p・1080pで全アイテムと待ち時間の一覧を描画。文字欠落・はみ出しを検査します。画像は `Logs/ItemFirstPlay/Captures/` に出力します。
2. `-batchmode -executeMethod DrivingTutorialValidation.Run`（`-quit`なし）：実シーン・実車・入力ゲートで両者が加速、旋回、アイテム取得、カウントダウンまで進むことを検証。段階間の位置・速度保持、リセットの押しっぱなし、取得完了音1回、箱への接近時間も検査します。`RACING_TUTORIAL_QA_OUTPUT` で画像の出力先を変更できます。
3. `-batchmode -executeMethod BalancePlaytestValidation.RunBatch`（`-quit`なし）：既存走行エージェントのアイテムありレース。準備を省略しますが、レース中は通常のハンドル・ペダル・必要時のリセット入力を使い、車体位置・速度・周回・結果を強制しません。人間の体験評価ではありません。
4. `sh Tools/Validate-Rgp.sh` とUnity EditModeテスト：既存の入力・CPU・レースルールの回帰。

テスト用に管理HTTPブリッジと遠隔送信を停止し、稼働中のサービスやシリアル機器に触れません。テストで生成された品質設定・既存マテリアル・旧レポートの差分は実装に含めません。

## 評価して調整した点

最初の描画では効果一覧が速度計に重なったため、運転中の表示を取りやめ、停止後に読みやすく表示する形にしました。箱の一部の面の記号の向きと発光の白飛びも描画を見て調整しました。

実走行の練習は約25m/sまで加速するため、元の18m先の配置では、計算上、箱まで約0.7秒しかありません。改善後のテストではP1が62.0m・2.50秒、P2が62.8m・2.51秒先で箱を確認でき、どちらも取得して次の段階へ進みました。

## 検証結果（2026年10月27日）

- Core回帰 **166/166**、Unity EditMode **166/166**。既存のRaceItemValidation、ArcadeUIValidationと新しいItemReadabilityValidationが成功。
- 箱の44三角形の外向き法線・全頂点のUV・寸法、再構築／無効化／再有効化時の重複防止、メッシュの再構築と破棄時のマテリアル・テクスチャ解放を確認。
- P1/P2それぞれ720pと1080pで、待ち時間の一覧・4アイテム・クリスタル・ハンドル反転被弾を描画。新しい表示の文字欠落・はみ出しなし。一覧が運転中は隠れ、取得後の待ち時間に現れることも確認。
- 実際の練習走行で両者が加速→旋回→アイテム取得→カウントダウンへ進み、完了音は各1回。最高速度26.078m/s、平地走行中の上下速度は0m/s。箱までの接近時間は上記のとおりです。
- 本番コース（1904.193m、2周、CPU2台）の `human-fast-items-7101` が終了。P1は1位、P2は3位でどちらも2周を完走。公式レース時計135.509秒、物理積算136.892秒。CPU2は2位で完走、CPU1はプレイヤー2人の完走によりレースが終わった時点で1周・4位の未完走でした。
- このレースでアイテム計8回（ロケット1・シールド5・オイル2）、クリスタル計9回、被弾計2回を記録。コンフューズはこの抽選では出ず、効果付与と表示は別のUnity検証で確認しました。P1の通常リセット1回・自動復帰1回を含むため、復帰なし完走とは扱いません。車体・周回・結果のテスト側からの強制はありません。
- 最終描画の選抜画像、実走行の練習画面、レースレポートと集計は `Artifacts/ItemFirstPlay/` に保存します。背景に既存の参照画像を使用したHUD検査画像は、実走行画像と区別しています。
- mainと景観ブランチは開始時・区切りで確認し、`1b170d6` / `c0d6158` から更新がありませんでした。景観ブランチの無条件マージは行っていません。

## 未検証・注意点

本番への反映やmainへのマージは行いません。既存のレース挙動PR #57とメンテナンスPR #58は別の提案として保持します。
