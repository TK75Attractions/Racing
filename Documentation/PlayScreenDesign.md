# プレイ画面のUIデザイン

## 方針

チャコールの半透明面、オフホワイトの文字、ミントとアンバーのアクセントを使う。
走行画面の中央を空け、四隅の情報に視線を移すだけで状況を確認できる構成にする。
パネルの角を切り落とし、円形のスピード計と組み合わせて形に変化を付ける。

日本語を主表示、英語を補助表示とする。順位には「位」「人」、周回には「周」、
残り時間には「秒」を付けて、小学生にも数値の意味が伝わるようにする。
「いまの周」「あなた」「あいて」など、短い言葉を使う。

## 画面構成

| 場所 | 表示 | デザイン |
| --- | --- | --- |
| 左上 | コース / COURSE MAP | 細いコース帯と方向マーカー。「あなた / YOU」「あいて / RIVAL」の凡例 |
| 左下 | 順位 / POSITION | 大きな太字の数字、単位「位」、参加人数 |
| 左下・順位の隣 | いまの周 / LAP | 現在の周、総周回数、単位「周」。アンバーのアクセント |
| 右上 | 走行タイム / RACE TIME | 総タイムを大きく、小数と「この周 / LAP」を補助表示 |
| 右下 | スピード / SPEED | 円形ベースに250度の分割アーク。高速度域のみアンバー |
| スピード計の上 | 加速中 / BOOST | 加速中だけ表示。残り秒数とバー |
| 上部中央 | アイテム通知 | 日本語名と、英語名・短い説明。1.6秒で退場 |
| 中央 | スタートまで / RACE START | 3・2・1、スタート! / GO!。走行開始後に非表示 |
| 上部中央 | もうすぐレース終了 / TIME TO FINISH | 2位のゴール待ち中に残り秒数を表示 |

アイテムの効果中は下中央の小さな通知に日本語と英語を併記する。
観戦中も同じパレットと文字を使用し、表示対象のプレイヤーを日本語で示す。

## 実装

- `RacingHUDBuilder` がレース状態と接続されるノードを構築する。
- `RacingHUDStyle` がHUD専用の色と日本語・英語の文字組みを管理する。
- `RacingHUDPlateGraphic` と `RacingSpeedGauge` はベクターメッシュを描画する。
- HUD文字には静的な M PLUS Medium（500）とBold（700）のSDFアトラスを使う。
  既存の可変フォントのThinデータを拡張する方式ではなく、太さを固定したフォントから焼き込む。
- 既存シーンのHUDを初期化時に置き換える。シーン保存や手動配置は不要。

## プレビューと確認

`Racing > UI > Capture Bilingual HUD Design` は、現在のコースを使った実装そのもののHUDを
既存のレース参考背景に重ね、`Artifacts/HUDDesign/` にPNGを出力する。
背景は走行中のキャプチャではない。ミニマップとHUDはUnityの実際の描画結果。

通常・加速・カウントダウン・終了警告・観戦を1920×1080で出力する。
1280×720と3840×2160の通常HUDも一時ディレクトリに出力し、文字の欠け・はみ出しを検証する。
`Racing > UI > Validate Modern UI` と `Racing > Validate MiniMap` で両プレイヤーの表示値、
日本語文字、加速表示、マップの投影とHUDとの重なりを確認する。

フォントを再作成する場合は、Git LFSのフォントを展開した状態で
`python Tools/UI/build_hud_font_sources.py`（fonttoolsが必要）を実行し、
Unityの `Racing > UI > Build HUD Fonts` でSDFアトラスを焼き込む。
