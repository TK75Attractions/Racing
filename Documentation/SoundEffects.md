# オリジナルSE音源

音源は `Assets/Resources/Audio/SFX/*.wav`。全20種類、48,000Hz／16bit／ステレオPCM。第三者の録音・サンプル・音楽・音声サービスを使わず、本プロジェクト用に制作した音源です。エンジンとBGMは変更しません。

ネオンのあるアーケードレースの雰囲気に合わせ、短い金属的なアタック、温かい低域、加速するスイープ、左右に広がる空気音、明るい和音を組み合わせています。操作音は短く、カウントダウンは一定の明確な音、GOは低音と上昇音、ゴールは約3秒のファンファーレです。走行SEはエンジンやBGMを覆いすぎないレベルにしています。

## 差し替え

同じ名前のWAVを置き換えれば再生内容が変わります。Unityの `.meta` を維持し、**Decompress On Load / PCM / Preload Audio Data ON / Load In Background OFF / Force To Mono OFF** にしてください。48kHz・ステレオ・無音の両端を推奨します。ピークは約−9dBFS以下を目安に、操作音はさらに控えめにします。インポート時の正規化は行いません。

`RaceSoundBank` は最初のアクセスで全音源を一度だけデコードし、両プレイヤーで共有します。差し替え後はPlayモードを再起動してください。新しい用途を増やす場合は `RaceSoundCue` の末尾へ追加し、同じ名前のWAVを配置します。音源が欠けている場合はエラーを記録し、その音を再生しません。

## 制作・検証

`python3 Tools/BuildRaceSoundEffects.py`（numpyが必要）で同じマスター音源と試聴ファイルを再制作できます。これは制作時だけ実行するツールで、ゲーム実行時には使いません。既存の音源を独自に差し替えた場合、再制作すると上書きされるため注意してください。`--check` はWAVを上書きせず、フォーマット・ピーク・DC偏り・無音の両端を検査します。結果は `Artifacts/SoundEffects/analysis.json` に出力します。

Unityの `Racing > Validation > Sound Effects` で音源読込、インポート設定、出力の分離、独立ミュート、ステレオ補間、モノラル化、コールバック分割時の一致、8音とBGMの同時再生を検証します。実機ではP1/P2別のブースト・取得・衝突・ゴール、最終周、SE/BGMの音量バランスを確認してください。
