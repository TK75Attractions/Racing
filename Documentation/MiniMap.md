# ミニマップ

レース中の画面左上に、コース全体と2台の車の位置を表示します。

- コース形状は `RaceCourse` がキャッシュしている内側・外側の縁をそのまま使うため、ウェイポイントを編集すると次の起動で自動的に反映されます。専用のアセットや画像は不要です。
- 形状のメッシュは初期化時に1度だけ組み立てます。毎フレームの処理は車マーカー2個の位置と回転の更新だけです。
- 追加のカメラや RenderTexture は使いません。2画面同時出力時の描画コストは増えません。
- 向きは固定（ワールド +Z がマップ上方向）です。自車の向きはマーカーの矢印で示します。
- 自車はシアン、相手は赤で表示します。自車のマーカーは常に相手より前面に描画します。
- `MainCanvas/OnPlay` の配下に置くため、タイトルとリザルトでは既存の画面遷移に従って自動的に隠れます。

## 構成

| クラス | 役割 |
| --- | --- |
| `MiniMapProjector` | コース全体のワールドXZ範囲を、ミニマップ矩形へアスペクト比を保ったまま収める座標変換です。MonoBehaviour ではないため、エディタ検証からも直接呼び出せます。 |
| `MiniMapTrackGraphic` | コース帯を1枚のUIメッシュとして生成します。内側と外側の縁を交互に並べた三角形ストリップです。`WidthScale` を1より大きくすると、縁取り用の一回り太い帯になります。 |
| `MiniMapMarkerGraphic` | 車を表す矢印です。スプライトを使わず頂点だけで描き、+Y方向を車の前方とします。 |
| `UIMiniMap` | `UILap` などと同じ `OnPlayUIManager` 配下のHUD要素です。ノードの生成、コース形状の焼き込み、マーカーの更新をまとめます。 |

実行時には `MainCanvas/OnPlay` の下に次の階層を生成します。シーンに `MiniMap` ノードが無い場合は自動で作成するため、2画面目の `MainCanvas` 複製でもそのまま動作します。

```
OnPlay/MiniMap        背景（Image）
├── Border            一回り太い暗色の帯（縁取り）
├── Track             コース帯
├── Marker_P2         相手の車
└── Marker_P1         自車（常に最前面）
```

## 画面配置

ミニマップの導入にあわせて、`SampleScene` の `OnPlay` 配下を次のように配置し直しました。ミニマップが左上を専有し、順位とラップは右列でタイムの下に縦に並びます。パネルの右端はタイムと揃えています。

位置は各要素のパネル画像（`Image`）の範囲です。テキストは左寄せのため、テキストボックス自体はパネルより外へ出ることがありますが、字面はパネル内に収まります。

| 要素 | `OnPlay` 上の `Anchored Position` | パネルの画面位置（1920 x 1080） |
| --- | --- | --- |
| MiniMap | 左上アンカー、余白 40, 40 | x 40〜340, y 40〜250 |
| Time | 変更なし | x 1490〜1910, y 213〜311 |
| Position | -840, 409 → **733.4, 192.7** | x 1579〜1910, y 340〜561 |
| Lap | -880, 290 → **750.2, 66.2** | x 1621〜1910, y 580〜742 |
| Speed | 変更なし | x 0〜532, y 657〜1064 |

## 調整

`Gmanager` の Inspector の `On Play UI Manager > Mini Map` で調整できます。

- `Map Size`：ミニマップ矩形の大きさ（ピクセル）。初期値 300 x 210。
- `Screen Margin`：画面左上からの余白（ピクセル）。初期値 40, 40。
- `Padding`：矩形の内側の余白。コースはこの内側に収まるよう自動で縮尺されます。
- `Map Rotation Degrees`：マップ全体の回転角。コースの形に合わせて矩形をより有効に使いたいときに調整します。
- `Marker Size`：車マーカーの大きさ（ピクセル）。
- `Track Border Scale`：縁取りの太さ倍率。1 にすると縁取りが消えます。
- 各色は `Background` / `Track` / `Track Border` / `Own Marker` / `Rival Marker` で個別に設定できます。

縮尺は `Map Size` と `Padding` から自動で決まります。縦横で同じ倍率を使うため、コース形状は歪みません。`SampleScene` のコース（約 474m x 346m）では約 0.6 ピクセル/メートルになります。

## 検証

Unity メニューの `Racing > Validate MiniMap` は、開いているシーンの `RaceCourse` を使って、コース帯の生成、矩形内に収まること、アスペクト比の維持、ワールド +Z がマップ上方向になること、ヤウ角とマーカー回転の対応、`OnPlay` 配下のノード生成、自車マーカーの前面配置、車未割り当て時のマーカー非表示、既存HUD要素（`Position` / `Lap` / `Time` / `Speed`）と重ならないことを検証します。

HUDの重なり判定はシーンの実配置から計算するため、後からHUDを動かしてミニマップに被せてしまった場合もここで検出できます。検証はシーンの `OnPlay` を書き換えず、同じ大きさの使い捨てノード上でミニマップを構築して比較します。

バッチ実行は次を使用します。

```
-batchmode -nographics -executeMethod MiniMapValidation.RunBatch -quit
```

実走では、両プレイヤーの画面で自車と相手の位置関係がコース上の実際の位置と一致するか、コーナーでマーカーの向きが進行方向を向いているかを確認してください。
