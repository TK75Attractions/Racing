# ハンドル警告・デバフ対象の改善

## 実機ハンドルの警告

左右135°以上で、そのプレイヤーの画面周囲を黄色にし、中央に大きなハンドルと戻す方向の矢印を表示します。右へ回しすぎた場合は「左にゆっくり戻してね」、左へ回しすぎた場合は「右にゆっくり戻してね」と表示し、ハンドルが中央へ戻る動きを繰り返します。125°未満まで戻すと解除します。ゲーム用のフルロック値やハンドル補正、ペダル入力ゲートとは独立し、ESP32の実角度を直接読みます。メニュー・チュートリアル・走行中・結果画面で有効です。通信断・古いデータでは表示を解除し、メンテナンス画面を優先します。警告は中央に表示し、操作入力は遮りません。物理的な回転を止める機能はありません。

## デバフと逆転の機会

- コンフューズは順位が自分より前の、最も近い順位の走行中の車へ。先頭から後方への自動攻撃はしません。前に妨害可能な相手がいないときは抽選から除外します。ゴール・中断・無効化済みの車は対象にしません。
- 3台以上のレースでは最後尾の走行車をオイル・コンフューズ・シールド接触によるスピンから保護します。人間とCPUに同じルールを適用します。
- 被弾中に最後尾になったときも、順位更新時に残りの妨害を解除します。自分のロケット・シールド・投下待ちのオイルは保持します。
- 他車がゴール・中断した後も、最後尾の走行車を保護します。2台だけの対戦では接触アイテムによる攻防を維持します。
