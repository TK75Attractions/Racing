# 建物の当たり判定

校舎のような背景モデルに当たり判定を付けるための開発用ツールです。2 通り用意しています。

| ツール | 形 | 向いている場面 |
| --- | --- | --- |
| `Racing > Fit Mesh Colliders` | **見た目どおり**（メッシュそのまま） | 凹凸や中庭があり、箱では形が合わない建物 |
| `Racing > Fit Box Colliders` | 外周を覆う箱 | 単純な直方体、または軽さを最優先したいとき |

どちらもシーンに置いた実体だけを変更します。FBX のインポート設定は触らないため、同じモデルの他の配置や非アクティブな複製には影響しません。

## 校舎の現状

- モデルは `Assets/Scenes/0715こうしゃ 1.fbx`（約 209MB）です。インポート設定の `Generate Colliders` は無効で、シーンの実体にも当たり判定がありません。
- `SampleScene` には 2 つ置かれています。動いているのは `0715こうしゃ 1 edit`（位置 679, 0.01, 848、スケール 3）で、`0715こうしゃ 1` は非アクティブです。
- コースのワールド範囲はおよそ x 258〜672、z 511〜797 です（`RaceCourse` は (500, 3, 500) に配置）。校舎はその北東の外縁に接しているため、車は実際に到達します。
- 校舎は `Default`、車は `CarBody`（レイヤー8）です。衝突マトリクス上は有効なので、当たり判定を付ければそのまま当たります。

## 見た目どおりに付ける（Mesh Colliders）

1. ヒエラルキーで校舎（`0715こうしゃ 1 edit`）を選択します。箱を試した後なら、先に `Racing > Fit Box Colliders > Clear Generated` で箱を消してください。
2. `Racing > Fit Mesh Colliders > Add To Selection` を実行します。配下のメッシュ 1 つにつき `MeshCollider` を 1 つ付けます。
3. 三角形数が多い場合は確認ダイアログが出ます。生成に時間がかかり、メモリも多く使うため、続けるかどうかを選べます。実行後はコンソールに個数と三角形数が出ます。
4. 取り消しは Ctrl+Z、消すときは `Racing > Fit Mesh Colliders > Clear From Selection` です。
5. 調整が終わったらシーンを保存してください。当たり判定はシーン側（プレハブインスタンスの上書き）に保存されます。

特徴と注意点は次のとおりです。

- 静的な当たり判定（非 convex）として付けます。車がすり抜けず、壁の形もそのままです。
- **非表示のパーツは対象外**です。見えていないものには当たり判定が付きません。表示を切り替えたときは付け直してください。
- すでに `MeshCollider` があるパーツは、重複して増やさずメッシュと設定だけ更新します。
- 内部の家具や細かい造作まで当たるようになります。車が引っかかる場所があれば、そのパーツの `MeshCollider` だけを削除してください。
- `Add To Selection (Convex)` は凸形状に丸めた当たり判定です。PhysX の制約で 255 三角形に簡略化され、くぼみは埋まります。小物には向きますが、校舎全体には向きません。

## 箱で付ける（Box Colliders）

1. 対象を選択し、`Racing > Fit Box Colliders > Whole Object`（全体を覆う箱 1 個）または `Per Child Part`（子パーツごとに 1 個）を実行します。
2. 生成された `GeneratedColliders` の下に `Box_<名前>` が並びます。シーンビューで位置と大きさを調整でき、複製して足すこともできます。
3. 作り直しは同じメニューの再実行（重複しません）、削除は `Clear Generated` です。

- 箱は**対象の座標系**で測るため、建物を回転させて置いていても向きが合います。親の拡大（校舎はスケール 3）も打ち消します。
- 生成済みの箱は次回の測定から除外するので、作り直しても範囲が膨らみません。
- 見た目の外周に沿うため、窓のくぼみや中庭も塞ぎます。形が合わない場合は Mesh Colliders を使ってください。

## 共通の注意

- `GroundCheck` は法線 y が 0.2 以上の面だけを接地とみなすため、壁が地面に化けることはありません。ただし**屋根や庇の上は走行できる面**になります。乗られたくない場合は、進入できる斜面や段差を塞いでください。
- FBX 側の `Generate Colliders` を有効にする方法もありますが、209MB のモデル全体が再インポートになり、非アクティブな複製にも当たり判定が付きます。シーン単位で調整できる上記 2 つのツールを先に試してください。

## 検証

- `Racing > Validate Mesh Colliders`：表示中のパーツにだけ付くこと、パーツ自身のメッシュを使うこと、非 convex であること、重複して付かないこと、形に沿う（範囲の角は素通りする）こと、convex への切り替え、削除、メッシュの無いオブジェクトで何もしないことを検証します。
- `Racing > Validate Box Colliders`：回転と拡大を持つ親の下での生成、対象の軸に沿うこと、親の拡大の打ち消し、作り直しで増殖も膨張もしないこと、物理クエリが当たること、削除、`Renderer` の無いオブジェクトで何もしないことを検証します。

バッチ実行は次を使用します。

```
-batchmode -nographics -executeMethod MeshColliderFitterValidation.Run -quit
```

```
-batchmode -nographics -executeMethod BoxColliderFitterValidation.Run -quit
```

実走では、校舎の四方から車を当てて、すり抜けが無いか、壁沿いに素直に滑るか、引っかかって止まる場所が無いかを確認してください。
