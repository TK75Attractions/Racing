# アイテム（チャージクリスタル / アイテムボックス）

コース上に置き、車が触れると効果が出る取得オブジェクトです。コントローラーにアイテム用ボタンがないため、**取った瞬間に自動で発動**します。

## 配置

Unity メニューの `Racing > Items` から作成します。

| メニュー | 内容 |
|---|---|
| `Create Charge Crystal` | チャージクリスタルを1個 |
| `Create Item Box` | アイテムボックスを1個 |
| `Create Item Box Row (3)` | コース幅に3個並べたアイテムボックス（親を動かすとまとめて移動） |
| `Auto Layout Items On Course` | コース全体へ自動配置（既存の `RaceItems` を作り直す） |

### 自動配置の規則

`RaceCourse` の中心線をスタートから走行方向（スタートのチェックポイントの向きで判定）にたどり、直線区間ごとに置きます。

- アイテムボックス3個の列：長さ180m以上の直線の45%地点。列どうしは250m以上離す。
- チャージクリスタル：長さ120m以上の直線で、次のコーナーの35m手前。コーナーの内側へ7mずらす。
- スタート後80m以内・スタート前30m以内と、加速度盤から15m以内には置かない。

`SampleScene` には、この規則で配置したボックス3列（スタートから約165m・720m・1073m）とクリスタル4個（約240m・425m・910m・1195m）が保存されています。バッチ実行（`-executeMethod RaceItemLayoutBuilder.RunBatch -itemCaptureDir <フォルダ>`）では、配置後に俯瞰図と各地点の画像も書き出せます。

- オブジェクトの原点を路面に置き、見た目と取得判定は `Hover Height` の高さに浮かびます。Inspector の `地面へ配置` で路面へ吸着できます。
- 取られると `Respawn Seconds`（初期値6秒）の間消えます。2人対戦では先に取った側が相手の分を奪えます。
- レース開始（リトライを含む）時にすべて再出現し、置かれたオイルも消えます。

## チャージクリスタル

触れるとドリフトチャージを増やします（`Charge Amount` = 1 で満タン）。チャージは**次にドリフトを解放するまで保持**されるため、クリスタルを取ってから次のコーナーで解放すると最大加速が出ます。チャージが既に満タンの車は取らずに通過し、クリスタルは相手のために残ります。

## アイテムボックス

触れると順位に応じて抽選し、その場で発動します。抽選の重みは Inspector の `Item Table` で変更できます。

| アイテム | 1位の重み | 2位の重み | 効果 |
|---|---|---|---|
| シールド | 50 | 15 | 6秒間、車体を泡が包む。シールド中に**相手の車へ当たると相手が1.2秒スピン**する（スピンさせるとシールドは消える）。シールド中は相手のオイル・コンフューズ・スピンを受けない |
| オイル | 50 | 20 | 0.5秒後に自車の4m後方の路面へ油だまりを置く。踏んだ車は2.2秒グリップが落ちて滑り、**画面に油が飛び散る演出**が出る。油だまりは踏まれると消える（置いた本人も1.5秒後以降は踏むと滑る） |
| ロケット | 0 | 35 | 3秒間の超加速（35 m/s 以上から最高 65 m/s）。この間は**自動操縦**になり、コース中心線の少し先へ向けて自動で走る。ロケット中はオイルとスピンを受けない |
| コンフューズ | 0 | 30 | 相手のハンドルを2.5秒間左右反転する。相手画面の縁がマゼンタに点滅する。相手がゴール済みのときは抽選から外れる |

各効果の時間・強さは車に自動で追加される `CarItemEffects` の Inspector（実行中の `Player1_Car` / `Player2_Car`）で調整できます。恒久的に変える場合は `CarItemEffects.cs` の初期値、または車の Prefab に `CarItemEffects` を追加して設定してください。

## 画面表示

各プレイヤー画面に `PlayerItemHUD` が表示されます。

- 取得・被弾時に、画面上部へアイテム名を大きく表示します。
- 効果中は画面下中央に残り時間を表示します（ロケット > スピン > コンフューズ > オイル > シールドの順で1つ）。
- オイルを踏むと画面が一瞬暗くなり、黒い油の飛沫が画面に付いて、垂れながら消えていきます。
- ロケット中は、既存の加速演出（Bloom・Motion Blur など）が最大強度で出ます。

## 検証

`Racing > Validate Race Items`（または `Unity -batchmode -executeMethod RaceItemValidation.Run -quit`）で、抽選表、コース中心線上の距離→座標変換、チャージ加算、各効果の付与・無効化、ロケットの発進速度を確認します。
