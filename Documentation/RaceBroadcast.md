# 第3画面のレース中継・リプレイ

## 画面とカメラ

- 実行ファイルを起動するとmacOS MetalではP1/P2と独立した `RACING — BROADCAST` ウィンドウを開く。Mac内蔵ディスプレイがあればその全面、なければメインディスプレイを使う。枠なしの独立ウィンドウで、背景をドラッグして移動できる。移動後に自動で元へ戻さない。別アプリへ切り替えると中継ウィンドウを隠す。第3画面の中継・結果ハイライトは標準で有効。
- EditorではP1/P2が使わないGameビューのDisplayに表示する。P2がDisplay 3の場合、中継はDisplay 2になる。Windows等はUnityが認識するDisplay 3がある場合に出力する（Mac用の独立ウィンドウ作成機能は使用しない）。
- レース中はP1/P2を交互に追う。コース両側に約70m間隔で求めた固定地点から、パンと望遠ズームを使って車両や接近戦を映す。建物等で遮られる構図は避け、チューブ等では近距離の追尾視点を使う。
- 非レース時は保存済みのハイライトを順番に流す。履歴がない場合、またはリプレイがOFFの場合は、実際の校舎・コースを映す `COURSE PV` に切り替える。架空のレースを過去映像として流さない。
- 中継専用の音声出力やAudioListenerは追加しない。P1/P2の音楽・操作には従来の出力を使う。

レース中の第3画面とゴール後の観戦画面は、大きな赤いLIVEバッジと「ただいまレース中」で強調する。REPLAY・COURSE PVではLIVEバッジを消す。詳しい検証は[スタート脇の屋根とLIVE表示](StartRoofAndLive.md)を参照。

## 記録と結果画面

実走行の車体・車輪のメッシュ位置と向き、塗色、速度、表示状態を最大15Hzで観測する。遅い描画時は実際に観測できたフレームを記録し、再生時に補間する。運転車両の位置・速度・周回や当たり判定を書き換える方式ではない。

順位が上がり、近くの走行車両との前後関係が入れ替わった場面を追い越し候補にする。高速の旋回、接近戦、完走も候補にし、重複を抑えて1レース最大8本を選ぶ。目立つ出来事がないレースは実際の終盤走行を使い、追い越し等の出来事として表示しない。巻き戻り・大きな位置飛び直後のイベントは除外する。

結果画面は左に大きなハイライト、右にレース順位と本日のランキング、下にラップ情報と再プレイ・タイトル復帰操作を置く。P1/P2は同じ映像を共有しつつ、順位・ラップ等の結果は各自の内容を表示する。リプレイは0.85倍速で流し、同じコース脇のカメラ演出を使う。

再生用車両はメッシュだけで構成し、Rigidbody・Collider・運転スクリプトを持たない。専用レイヤー29で通常のプレイヤーカメラから除外する。元の走行車両はリプレイカメラを描画する瞬間だけ表示を抑え、描画後にフラグを復元する。追加の3D描画は共有1280×720映像1つで、第3画面と結果画面2枚から同じTextureを参照する。

保存先は `Application.persistentDataPath/BroadcastHighlights/race-*.rpl`。直近3レースを保持し、次回起動後の待機画面にも使う。保存は一時ファイルからの置き換えで行う。読み込み時はバージョン、サイズ、フレーム数、メッシュ参照、有限値、時間順序を検証し、読めないファイルはスキップする。保存失敗時もその実行中のリプレイは保持する。

このリプレイは記録した車両の動き・見た目を現在のコース上に再現する。天候や一時的なアイテム・火花等の全エフェクトを過去状態へ戻す機能ではない。コース・車両モデル構成を変更した版で互換性のない履歴は読み飛ばす。

## デバッグと検証

2026-10-23以降、中継・走行記録・結果ハイライトは標準機能として有効にする。F8は指定された6つの任意項目だけを表示する。

`BroadcastValidation.RunPlaythrough` は実際のSampleSceneを人間に近い操舵入力ボットで走らせ、中継、保存・読み戻し、不正ファイル拒否、再生車両と物理の分離、結果画面を確認する。検証専用の履歴フォルダを使い、実プレイのランキングや履歴を汚さない。音声出力・管理サーバー・外部公開は停止する。

```sh
/Applications/Unity/Hub/Editor/6000.3.9f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -projectPath "$PWD" -executeMethod BroadcastValidation.RunPlaythrough \
  -logFile Logs/BroadcastPlaythrough.log
python3 Tools/EncodeBroadcastEvidence.py Logs/BroadcastPlaythrough
```

非撮影部分は4倍速で検証し、実況の撮影中と結果の再生は等倍時間で進める。動画は実際に得られたフレームと時間間隔から作る無音の検証映像で、描画性能のベンチマークではない。代表映像・画面・テスト結果は `Artifacts/Broadcast` に記録する。
