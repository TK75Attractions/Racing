# LAP1/LAP2・練習復帰・チューブのタイヤ駆動（2026-10-30）

前周比をLAP1とLAP2のタイム欄へ置き換える。初周は表示せず、2周目にLAP1の確定タイムとLAP2の進行中タイムを表示する。ゴール時は両周のタイムを保存し、現在ラップの時計が0へ戻ってもLAP2の確定値を維持する。観戦先を変えた場合はその車の値へ切り替え、再レースでは非表示からやり直す。合計タイムと同じ精度・書式を使い、タイム欄と走行案内の間に収める。

練習では、道路の中心線から横へ13m超外れる、ペダルを0.05超踏んでも2m移動できない、80°以上正面から向きがずれる（2輪以上の接地中）、横転する状態をそれぞれ計測し、3秒継続すると現在の課題に合った道路へ復帰する。一度始まった詰まりの時計は、ペダルを離しても1m/s（時速3.6km）以下なら継続する。1m/sを超えた状態で2m進めば詰まりの時計をリセットし、ペダルを離して速度がしきい値を超えた場合も解除する。道路へ戻ればコースアウトの時計をリセットする。待っているだけの人を繰り返し動かさないため、最初から無入力で停止している場合は詰まりの時計を始めない。接続切断・踏み直し待ち・復帰直後の入力抑制・練習終了中は計測しない。完了済みの課題と練習の残り時間を保持し、片方の復帰で相手を動かさない。大きく落下・練習エリア外へ飛び出した場合の即時救出と、箱を通り越した時の0.5秒復帰は維持する。

チューブでは下向きの接地レイに加え、タイヤの球コライダーとチューブメッシュの実接触を記憶する。路面の端と壁の境目でレイが外れた前輪には、本来の前輪駆動を進行方向へ補う。壁に接したタイヤ1本につき基本の駆動力の4%分、2本以上で最大8%分を追加し、従来の抵抗低減による速度報酬をこの駆動力へ置き換える。普通の抵抗を保つため報酬は重複せず、速度を毎フレーム乗算しない。力は重心へ加え、人工的な横転・旋回トルクを作らない。

この補助は前進ペダルを踏んでいる時だけ有効。入力切断・入力抑制・踏み直し待ち・オイル・コンフューズ・スピン・ロケット中には補助しない。離れた接触、無効なチューブ、飛行中の古い接触は採用しない。平らな路面・一般の柱や柵・他車の接触は壁走行の報酬対象にしない。

## 検証

`LapPracticeTubeValidation.Run` は本番の周回完了処理、LAP表示、練習復帰、壁の力と通常抵抗、既存のUI・復帰検証を実行し、P1/P2のHUDを描画する。`LapPracticeTubeValidation.RunPhysics` は空の検証シーンに本番車両を生成し、左右の壁のみ／道路と壁の境目の4条件で実際のタイヤ接触と前進を測る。壁に接したままの状態を一定に保つため、位置・回転のうち前後移動以外を固定し、コース復帰や姿勢補助を分離して駆動を確認する。空中・切断・ペダル解放の解除条件も確認する。

証跡は `Artifacts/LapPracticeTube`、HUD画像は `Artifacts/ArcadeSportUI/race-p1.png` と `race-p2.png`。実機ハンドル・実コースでの手動運転の確認は別途必要。

確認結果：コア196件、画面・復帰・既存UI回帰、および4条件の実接触による駆動検証を通過。壁のみでは下向きレイの接地0輪でも約1.2秒で10.19m、道路との境目ではレイ接地2輪で18.97m前進した。未入力時の移動は測定誤差内。いずれも壁に接したタイヤ2輪を検出した。検証中のみ校舎FBXのLOD生成を省略し、元の設定へ復元済み。Unity Editor内蔵検索の既知の索引例外が起動時に1件出たが、物理検証は完走した。
