# 操舵・回転数・ブースト表示

[デザイン2](ArcadeSportUI.md) の共通 HUD は左に速度、右にタコメーターとブースト外周、下中央にハンドル角を一つ表示します。チュートリアルでも同じ部品を使います。

ハンドルは従来の `RacingSteeringIndicator` の構造を維持します。速度別の有効範囲を帯で示し、白いカーソルは制限後の実操舵位置、細い目印は要求角です。P1 は青、P2 はピンクの配色です。

回転数はエンジン音と同じ `CarSoundController.CurrentRpm` を参照します。外側のブースト計はドリフト蓄積と発動中の残量を示し、加速度盤・ロケット・追走・着地の加速にも対応します。描画を段階化し、値が変わらないフレームのメッシュ再構築を抑えます。

旧来の加減速専用メーターとペダルパネルは HUD に生成しません。`RacingAccelerationGauge` の計算部品は互換用に残っていますが、現行の右メーターはタコメーターです。

`Racing > UI > Validate Arcade Sport UI` で両プレイヤーの共有部品と結合を確認し、`Capture Arcade Sport UI` で確認画像を出力できます。
