# 操舵・加減速インディケーター

## 操舵

各画面下端の操舵表示は、1080p基準で軌道10px、中央から伸びる帯14pxとし、従来の約3倍の太さにした。白いカーソルは7pxと暗い縁取り、軌道には暗い下地を付ける。速度別の有効範囲、上限外の暗い両端、入力位置と実操舵位置の区別は維持する。

## 加減速

スピードメーター外周に、12時の位置をゼロとする弧を追加した。

- 加速: 青い弧が右側へ時計回りに伸び、「加速」と表示する。
- 減速: 赤い弧が左側へ反時計回りに伸び、「減速」と表示する。
- 一定速度・停止: 明るい弧を消し、「一定速」と表示する。

ペダルの踏み込み量ではなく、車両の走行速度の変化 `a = (v - 前回v) / 物理刻み` を使う。ペダルを踏んでいても一定速なら消灯し、ペダルを離した惰性の減速でも赤く表示する。後退中も速度の大きさが増えれば加速、減れば減速になる。

速度は `DebugMover.SpeedMetersPerSecond` を参照し、接地中は路面に沿った速度、空中は水平速度を使う。落下速度を駆動の加速として数えない。表示は時定数0.12秒で平滑化し、±0.35 m/s²未満は中立とする。弧のフルスケールは±20 m/s²で、左右各90度・30段階。衝突の極端な瞬間値は平滑化前に±40 m/s²へ収める。

観戦対象の切り替え・HUDの無効化・運転終了時は計測履歴を捨てる。リスポーン入力抑制中も速度基準を更新し直すので、ワープや速度のリセットで架空の加減速を表示しない。

スピードメーター下にあった旧ペダル・小型ハンドルパネルは生成しない。再初期化時に旧パネルが残っていれば無効化する。旧 `RacingTelemetryUI` とそのメタファイルも削除した。

## 検証

Unityメニュー `Racing > UI > Validate Steering and Acceleration Indicators` で、速度の増減・一定速・停止・リスポーン相当のリセット・フルスケール・微小ノイズ・50/100 Hzでの平滑化の一致を確認できる。

全HUD検証と720p/1080pの加速・減速・一定速プレビューを生成する場合:

```sh
Unity -batchmode -projectPath "$PWD" \
  -executeMethod HudIndicatorValidation.RunBatch -quit \
  -logFile Artifacts/HudIndicators/validation.log
```

[今回の測定と画像](../Artifacts/HudIndicators/README.md) を参照。フォントの再生成時にはTMPの字形検索キャッシュも更新し、同じEditorセッション内で追加文字が表示されるようにしている。
