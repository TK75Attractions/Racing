# 画面と時間制限（2026-10-29）

`SampleScene`の設定と実行コードに基づく。マップ追加では時間設定を変更していない。

| 画面・段階 | 現在の時間と進み方 |
| --- | --- |
| タイトル | 自動終了なし。各自がペダルを離してから踏み、練習を開始する。 |
| 運転練習 | 各プレイヤー60秒。加速・ハンドル・箱の取得を完了すれば早く進む。時間切れでも説明に進む。 |
| しかけ・アイテム説明 | 4ページ、各10秒で自動進行。各ページ4秒経過後はペダルを一度離して踏むと早送りできる（最短約16秒、通常40秒）。 |
| 相手の準備待ち | 自動終了なし。両者の練習・説明が終わるまで待つ。相手がタイトルにいる場合も含む。 |
| コース紹介 | 9秒（飛行7.25秒＋車への引き継ぎ1.75秒）。機能を無効にした場合は省略。 |
| スタートカウント | コース紹介の後に3秒。GO表示0.75秒は走行時間内。 |
| 通常レース | 2周、走行開始から最大360秒（6分）。未完走車はDNFとして結果へ。 |
| 体験モード | 1周、走行開始から最大180秒（3分）。 |
| 人間の片方がゴールした後 | 基本40秒。残る人の距離とそれまでの平均ペースから、通常は最大180秒、体験は最大90秒まで猶予を調整する。ただしレース全体の6分／3分は超えない。CPUのゴールだけでは猶予を開始しない。 |
| 猶予終了直前の救済 | 残り100m以内・前進速度3m/s以上なら、一度だけ3〜12秒の追加機会を与える。猶予とレース全体の上限は超えない。 |
| ゴール演出 | 5.5秒。先にゴールした人は、その後相手の観戦へ。全体終了後に結果画面へ。 |
| 結果 | 自動終了なし。最初の3秒はペダル決定を受け付けず、その後一度離してから1秒踏み続けると、お礼画面へ進む。 |
| お礼 | 自動終了なし。一度離して0.65秒踏むとタイトルへ戻る。 |

タイトルから終了までを通したタイマーはない。特にタイトル・相手の準備待ち・結果・お礼は無期限なので、利用者交代までの総時間は固定されない。

一時停止メニューはそのプレイヤーの操作を止めるが、レースの時計は進む。メンテナンスモードはレースと練習の進行を停止する。

## 設定元

- `Assets/Scenes/SampleScene.unity`: 練習60秒、通常レース360秒、カウント3秒、猶予40〜180秒、ゴール5.5秒、結果入力待ち3秒。
- `Assets/Managers/Multiplayer/Core/RaceFeatureSettings.cs`: 通常2周（シーン設定）、体験1周・180秒・猶予最大90秒。
- `Assets/Managers/Multiplayer/Core/TutorialGimmickBriefing.cs`: 4ページ・10秒・早送りは4秒後。
- `Assets/Managers/CourseIntroDirector.cs`: コース紹介9秒。
- `Assets/Managers/Multiplayer/Core/RaceParticipantSession.cs`: 全体制限、完走猶予、ゴール直前の救済。
- `Assets/Managers/Gmanager.cs` / `Assets/Managers/UI/ArcadeEndingUI.cs`: 入力待ち・結果とお礼画面。
