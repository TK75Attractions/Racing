# 画面と時間制限（2026-10-30 更新）

| 段階 | 現在の動作 |
| --- | --- |
| タイトル | スタート操作を待つ。時間制限なし。 |
| レース前の全体 | **最初のスタート操作からレース開始まで最大60秒**。各自の開始操作でその画面だけ練習へ進む。未開始側はタイトルに残る。共通の準備期限では未開始側の練習を飛ばしてレースへ進め、相手待ち・画面遷移・コース紹介・3秒カウントも60秒に含む。 |
| 操作練習 | 最大35秒。加速・曲がる・箱の取得を完了すれば早く次へ進む。未完了でも時間で説明へ進む。 |
| 必要な説明 | ジャンプ／加速／箱の自動使用／すべった時の操作の4項目を1画面で一覧表示。8秒で自動進行（4秒後から踏み直して早送り可）。ドリフト・追走・全アイテム効果の説明は省略。 |
| 準備の締め切り | 45秒で練習・説明を終了する。57秒までにコース紹介を終え、残り3秒以内のカウントを行う。早く準備できれば早く開始する。 |
| レース | **通常レースのみ、2周・最大180秒**。体験モードの選択肢はゲーム内設定・管理画面・設定APIから削除。旧設定の360秒も180秒を超えない。 |
| 片方の完走後 | 従来の残り距離・ペースに応じた猶予を使うが、走行開始から180秒の期限を超えない。未完走車はDNF。 |
| ゴール演出 | 5.5秒。先にゴールした人は相手を観戦する。 |
| 結果 | **各画面で実際に結果が表示されてから15秒**。右下に`00:15`からのカウントダウンを表示し、0秒で自動的に退出案内へ切り替える。ペダル操作でも早く次へ進める。 |
| 退出案内 | 「ペダルから あしをはなし、ゆっくり おりてね。」を表示する。表示から5秒で自動的にオープニングへ戻る。ボタン、またはペダルを離して0.65秒踏む操作でも早送りできる。 |

タイトルでの入場待ちには時間制限を設けない。通常の一時停止メニュー中も時計は進む。メンテナンス中は準備・レース・結果・退出案内の進行を止める。

## 設定と検証

- `PreRaceCountdown`: 両画面共通の60秒・準備45秒・最終カウント3秒。重複スタート操作では期限を延長しない。
- `DrivingTutorialProgress` / `TutorialGimmickBriefing`: 練習35秒・説明1画面・8秒。処理落ちでも説明の時計を引き延ばさない。
- `SampleScene` / `RaceRuleSet`: 通常2周・180秒。完走猶予も180秒の全体期限内。
- `Gmanager.UpdateResultDisplay`: 各画面の結果表示を15秒計測し、入力やもう一方の画面遷移を待たず退出案内へ進む。
- `ShortVisitorFlowValidation.Run`: 実シーンを入力なしで開始し、準備の実時間、レースの180秒タイムアウト、結果15秒後の両画面の退出案内を検証する。レース区間だけ時間倍率を上げ、準備と結果は実時間で計測する。証跡は`Artifacts/ShortVisitorFlow`。
