# レース前の必要な説明

操作練習のあと、現在のアーケードUI・ふりがな・実際のゲーム写真を使った2ページだけを表示する。

1. **ジャンプと加速**：金色の台はまっすぐ進む。加速パネルは踏むと加速する。
2. **箱と復帰操作**：光る箱に触れると自動でアイテムを使う。ボタン操作は不要。すべったらペダルをゆるめる。

ドリフト、追走、各アイテムの効果一覧、クリスタルの説明は省略した。これらのゲーム機能自体は維持する。

練習は最大35秒。説明は各4秒で自動進行し、2秒後からペダルを離して踏むと次へ進める。操作しなくてもレースに進む。両画面は最初のスタート操作で同時に準備へ入り、紹介・カウントを含めて60秒の共通期限を使う。

`TutorialGimmickCapture.Run`は2ページを両プレイヤー・720p/1080pで検証する。`ShortVisitorFlowValidation.Run`は入力なしの実際の時間進行と画面を確認する。現在の時間制限全体は`Documentation/ScreenTimeLimits.md`を参照。
