# 実画像で学ぶコース予習

操作練習（加速・曲がる・アイテム取得）のあとに車を停止し、レース前に4画面を表示します。操作練習が60秒で時間切れになった人にも表示します。コースとアイテムの画像はUnityの実際のコース・車・アイテム・HUDを撮影したものです。図解用の車・道路描画は使用しません。

| 画面 | 内容 |
| --- | --- |
| 1 | 金色のジャンプ台と、チューブ内に置いた既存の加速パネル。実際に見える外観と、踏み方を説明。 |
| 2 | ドリフトの実車・火花と、2台の実車による追走。操作と加速の関係を説明。 |
| 3 | 本物の光る箱→接触して箱が消える→自動発動の写真を順番に強調。シールドなど発動後の写真も切り替わる。ボタン操作が不要なことを明示。 |
| 4 | シールド・ロケット・オイル・コンフューズの効果一覧と青いクリスタル。相手待ち中もこの実画像一覧を残す。 |

## 進行

各画面は10秒で自動送り。4秒読んだ後ならペダルを離して踏むと次へ進みます。長押し・早押し・通信復帰時の踏みっぱなしは読み飛ばしません。2人は独立して進み、両者が完了してからレースへ進みます。説明中は車を停止し、メーター・練習タイマーを隠します。メンテナンス中は説明・アニメーションも停止します。

## 実画像と演出の再生成

- `TutorialPhotoBuilder.Run`: SampleSceneのジャンプ台・設置済み加速パネル・実車・実際のアイテムと効果を撮影し、`Assets/Resources/UI/TutorialPhotos` へ保存。撮影用に車を配置し、実際の効果を有効にした静止画です。ロケット・反転は本来のHUDを含めて撮影します。
- `TutorialGimmickCapture.Run`: 両者の720p/1080p・全4画面を検証。1920×1080の画面例を `Artifacts/TutorialGimmicks/Preview` に保存。画面全体の背景には参照画像を使い、カード内の画像とUIは実装したものです。
- `DrivingTutorialValidation.Run`: 実走して操作練習→停止中の予習4画面→カウントダウンを確認し、両者の全8画面を `Live` に保存。登場アニメーション完了後に撮影します。
- `TutorialRealPhotoValidation.Run`: 加速パネルの配置・既存加速処理、実画像、全UI、箱と矢印のアニメーションをまとめて検証。

## 検証範囲

コア・Unity EditModeは各182件成功。実走でも両者が全4画面を見てからカウントダウンへ進むことを確認しました。全4画面×2人×720p/1080pで写真の読み込み・文字欠け・はみ出し・入力透過を確認。箱の強調順序と各アイテムの字幕も検証しています。

実機ハンドル・ESP32、Windows実機、小学生の理解度は未確認です。既知のUnity Editor SearchDatabase起動時例外は引き続き出ます。元mainの未コミット変更2件と、作業用チェックアウトの設定・マテリアル3件は保持し、PRには混ぜていません。
