# レース前の必要な説明

操作練習のあと、現在のアーケードUI・ふりがな・実際のゲーム写真を使った4項目の一覧を、2列×2段で1回表示する。

1. **ジャンプ**：金色の台はまっすぐ進む。
2. **加速**：加速パネルは踏むと加速する。
3. **箱**：光る箱に触れると自動でアイテムを使う。ボタン操作は不要。
4. **すべった時**：ペダルをゆるめ、道にそって戻る。

ドリフト、追走、各アイテムの効果一覧、クリスタルの説明は省略した。これらのゲーム機能自体は維持する。

練習は最大35秒。説明は8秒で自動進行し、4秒後からペダルを離して踏むと次へ進める。操作しなくてもレースに進む。操作した本人から練習を始め、紹介・カウントを含めて60秒の共通期限を使う。

`TutorialGimmickCapture.Run`は4項目の同時表示を両プレイヤー・720p/1080pで検証する。`ShortVisitorFlowValidation.Run`は入力なしの実際の時間進行と画面を確認する。現在の時間制限全体は`Documentation/ScreenTimeLimits.md`を参照。
