# 初めて遊ぶ人向けのコース予習

操作練習（加速・曲がる・アイテム取得）のあとに車を停止し、レース前に3画面を表示します。アイテム取得直後に2人とも準備完了になっても省略されません。操作練習が60秒で時間切れになった人にも表示します。

| 画面 | 説明 | 伝える操作 |
| --- | --- | --- |
| 1. コースのしかけ | 金色のジャンプ台、チューブの光るライン | ジャンプ台はまっすぐ進む。ラインを走り切るとチャージがたまる。ふつうに走ってもよい。 |
| 2. 慣れたらチャレンジ | ドリフト、前の車を追う加速 | 曲がってためて、少し逆に切って加速。前の車の後ろを少し追うと加速。接触を避ける。 |
| 3. アイテムと安全操作 | シールド・ロケット・オイル・コンフューズ・青いクリスタル | 箱はふれるだけで自動発動。赤い画面はハンドルの回しすぎ。滑ったらペダルを緩める。 |

## 表示・進行

- 各画面10秒で自動送り。入力がなくても計30秒で終わります。遅いフレームでは読み飛ばしを防ぐため時間を補いません。
- 4秒以上読んだら、ペダルを離してから踏むと次へ。踏みっぱなしや早すぎる入力では進みません。通信復帰後も新たなペダル解除を確認します。
- P1・P2は独立して読み進めます。両者が説明を終えるまでレースのカウントダウンを始めません。
- 説明中は車を停止し、メーターと練習の残り時間を非表示にします。説明画面は操作入力を遮りません。メンテナンス中は既存の停止処理と同じく説明の進行も停止します。
- 管理画面の状態にも `CourseGuide 1/3` のように進行を表示します。
- 静的な日本語フォントを396文字へ更新。図はUnity UIのメッシュで描き、追走の図には流れる線を加えています。
