# 坂道のカメラとチューブ側面の走行

## 高速構図・旋回先読み・遮蔽回避（2026-10-21、バックログ25〜27）

追従距離の既定値を5.8 mに変更。速度50 m/s（180 km/h）まで滑らかに高さを最大0.8 m、注視距離を3→7 mへ増やします。接地中・5 m/s超では水平旋回速度を0.4秒で平滑化し、4度/秒の不感帯を超えた分だけ先読みします（0.35秒先、最大8度・横1.5 m）。空中では先読みを戻し、従来の路面ピッチ・水平維持は継続します。各値はInspectorで調整できます。

車体上方向へ0.8 m離した起点からカメラへ半径0.35 mのSphereCastを行い、壁・チューブに当たれば余白0.12 mを残して即座に寄せ、復帰だけ0.25秒で平滑化します。トリガーと車両は除外し、`TubeDriveSurface`は遮蔽物に含めます。速度演出側でも各プレイヤーの描画直前に最終位置を制限し、引き・揺れによる再侵入を防ぎます。追従先の切替時には観戦先を再解決します。

Unityでの動作確認は未実施です。リードは`CourseVisualTour`の定点を使い、P1/P2の180 km/h・ブースト中のカーブ／相手車の見え方と、チューブ入口・カーブ・壁面／天井走行の壁抜け・寄せ戻りを確認してください。現行撮影の移動速度は25 m/sなので、180 km/hは別途50 m/sを与えて確認が必要です（撮影コードは未変更）。既存検証は静止時の距離に合わせた視線角と、振動検証を遮蔽物から分離する設定を更新しています。

`RaceDirectionCameraController` は、2本以上のタイヤが接地しているときに路面法線から進行方向の勾配を求め、カメラの上下角を滑らかに追従させます。標準の角度上限は30度、平滑化時間は0.3秒です。注視点は車両の3 m先に置きます。坂に沿った移動分はカメラの高さへ先に反映し、車体の上下振動だけを従来のフィルターで抑えます。ロールは追従せず、離陸後は路面の上下角を保ちます。リスポーン時は追従位置と平滑化状態を即座に更新します。

チューブ内壁は、`RaceCourseRoad.Settings.tubeInterior` に設定された MeshCollider に道路生成時に `TubeDriveSurface` を付けて識別します。シーンやFBXの編集は不要です。この面では世界の上方向に対する角度だけで接地を切らず、タイヤまでの距離と車体上方向との一致を使います。建物の壁には従来の角度制限を適用します。チューブを壁反発・侵入復帰・壁の火花／衝突揺れの対象から除外します。

`DebugMover` の駆動、操舵、速度抵抗、ドリフトのスピン抑制、ブーストは接地面を基準にします。これにより、バンクした路面で車体前方の上下成分を消して横グリップが前進を妨げることや、世界の鉛直軸でドリフト補正して路面に押し付ける／離れる動きを防ぎます。全輪が離れている間は従来の水平面を基準にします。

## チューブ壁面でのコース判定と自動復帰（2026-10-19）

走行範囲には設定されたチューブの内部も含めます。上下・左右・前後の対向方向に実際の壁を横切る回数で内外を判定し、チューブの境界ボックス内でも壁の外側にある位置は含めません。チューブ内部は、中心線との高さの差だけで落下扱いにしません。

チューブの接触面は角度にかかわらず壁の詰まり検出に含めます。ペダル入力があるのに約4秒間、2 m以上移動できない場合は安全な道路へ復帰します。接触中の転倒判定も壁面法線を基準にするため、側面や天井を走っているだけでは転倒扱いになりません。

`Racing > Validate Tube Wall Recovery` で通常の壁の回帰検証に加え、左右の壁・天井を含む10通りの姿勢について、通常走行・無入力・小刻みな揺れと復帰を検証します。状態を与えて復帰処理を実行する検証で、手動の実走とは区別します。`TubeWallRecoveryValidation.RunFullBatch` は実コースのチューブ内側と既存のバンク駆動・カメラ検証も実行します。

## 回帰検証

Unity 6000.3.9f1 で `Racing > Validate Slope Camera And Tube Driving`、または次を実行します。

```sh
/Applications/Unity/Hub/Editor/6000.3.9f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -nographics -projectPath "$PWD" \
  -executeMethod SlopeTubeDrivingValidation.Run -quit \
  -logFile "$PWD/Artifacts/SlopeTubeDriving/unity.log"
```

検証用の平面を0度、左右60／80／90度に傾け、面の長手方向から25度向きを変えた4輪車で1秒間の駆動を比較します。重力を無効にし、加速比較中の姿勢を固定することで重力・遠心力と駆動の問題を区別します。ドリフトでは姿勢固定を解除し、速度維持、法線方向の速度、旋回軸を検証します。80／90度の面からマーカーを外すと、接地できないことも確認します。

カメラは実際の路面へのレイ判定を使い、±20度の坂、平地、路面に沿った移動と振動、離陸中の車体回転、リスポーンを検証します。既存のカメラ振動・操舵・ドリフト・視覚効果の回帰検証も実行します。検証用オブジェクトは保存しません。実コースでの周回と描画は `TubeGameplayCapture.RunBatch` で別途確認しています。結果は [Artifacts/SlopeTubeDriving/README.md](../Artifacts/SlopeTubeDriving/README.md) を参照してください。

チューブ壁面データの生成: Unity 6000.3.9f1 で `-batchmode -nographics -projectPath <プロジェクトパス> -executeMethod TubeWallVisualPreparation.Run -quit -logFile <ログパス>`（または SampleScene を開き Racing > Prepare Tube Wall Visuals）をリードが実行する。
TubeCourseData に読み取り可能な TubeWallSource.asset と UV2 付き TubeWallOverlay.asset を冪等に生成し、参照とリング中心をシーンに保存する。FBX の Read/Write 設定は変更しない。
