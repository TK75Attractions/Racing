# 機能拡張・実行中の比較デバッグ

## 操作

ゲームのキーボード入力を受けるウィンドウで **F8** を押すと比較用パネルを開閉します。Editorと通常ビルドの両方で使えます。ゲームを一時停止せず、マウスで両プレイヤー共通のスイッチを変更します。Inspectorを探す必要はありません。

パネルは操作PC側だけに出ます。ハンドル・ペダルには追加操作を割り当てません。設定はディスクへ保存せず、アプリ再起動で既定値に戻ります。

## レース設定

- **Standard**：シーンの周回数・制限時間を使用します（通常2周、360秒、先着後40〜180秒）。
- **Experience**：1周、最大180秒、先着後の猶予は基本40秒〜最大90秒。どちらも全体上限が優先します。
- 最初のプレイヤーが車選択へ入った時点で、両者の周回と締切を固定します。準備中・走行中のプリセット操作は **次レースへの予約** です。現在と予約先をパネルに併記します。
- リトライは選択中のプリセット、次の組でタイトルへ戻すとStandardになります。
- **Gentle items** は走行中に即時切替できます。ONでは1位はシールド、2位以下はロケット。CPUは従来どおりアイテムを取得しません。
- 「All added features OFF」は追加機能をまとめて無効にします。周回・締切は途中変更しません。

## 検証

`Tools/Validate-Rgp.sh` で設定の固定・予約・個別切替と既存セッションのテストを実行します。Unityメニュー `Racing > Validation > Gameplay Features` はUnity側の検証入口です。

人による理解度・楽しさや、実ハンドル／2画面／2音声機器の評価は自動テストと分けて行います。
