# 機能拡張・実行中の比較デバッグ

## 操作

ゲームのキーボード入力を受けるウィンドウで **F8** を押すと比較用パネルを開閉します。Editorと通常ビルドの両方で使えます。ゲームを一時停止せず、マウスで両プレイヤー共通のスイッチを変更します。Inspectorを探す必要はありません。

Macでファンクションキーがメディア操作に割り当てられている場合は、fn+F8を使います。

パネルは操作PC側だけに出ます。ハンドル・ペダルには追加操作を割り当てません。設定はディスクへ保存せず、アプリ再起動で既定値に戻ります。

## レース設定

- **Standard**：シーンの周回数・制限時間を使用します（通常2周、360秒、先着後40〜180秒）。
- **Experience**：1周、最大180秒、先着後の猶予は基本40秒〜最大90秒。どちらも全体上限が優先します。
- 最初のプレイヤーが車選択へ入った時点で、両者の周回と締切を固定します。準備中・走行中のプリセット操作は **次レースへの予約** です。現在と予約先をパネルに併記します。
- リトライは選択中のプリセットを使います。次の組でタイトルへ戻すと通常はStandardへ戻りますが、明示的に予約したプリセットがあれば予約を優先します。
- **Gentle items** は走行中に即時切替できます。ONでは1位はシールド、2位以下はロケット。CPUは従来どおりアイテムを取得しません。
- 「All added features OFF」は追加機能をまとめて無効にします。周回・締切は途中変更しません。

## ドリフト案内と被弾保護

**Drift coaching** は、路面の広い穏やかな通常区間で、ドリフト中に「曲がってためる」、蓄積後に「少し逆に切って加速」を一度ずつ表示します。実際の解放加速に成功すると短い通知と音を返します。ジャンプ・復帰・切断案内が優先し、被弾・空中・壁面走行中には新しい操作案内を出しません。OFFにすると表示中の案内も消えます。

**Anti-chain hit protection** は、オイル・反転・スピンを同時に重ねず、1回の効果を最大3秒に制限し、その終了後1秒間を保護します。ジャンプ直前・空中では新たな妨害を受けません。OFFはこの追加制限だけを外し、従来のシールド・ロケット・復帰後保護は維持します。

Gentle itemsを走行中にONへ切り替えると、残っているオイル・反転・スピンと設置済みオイルを解除します。通常の被弾保護とは別のスイッチです。

## スリップストリーム

**Slipstream boost** がONなら、人間の車が前車の後方6〜20m・横ずれ2.5m以内を約0.9秒追走すると、自動で0.7秒間、小さく加速します。「追走で加速！」と既存の加速演出で知らせます。同じレースに参加している人間・CPUを追走できます。CPU自身はこの加速を使いません。

- 通常の穏やかな直線で、2輪以上が接地し、速度8m/s以上のときだけ蓄積します。
- 高さ・向き・コース進捗・視線を確認し、立体交差の上下、壁越し、逆走、横並びでは成立させません。
- ジャンプ手前45m、空中、壁面走行、妨害中、ロケット中、入力切断・入力抑制中は無効です。
- 追加加速度は最大4m/s²。既存のドリフト・パッドとの加速度合計が18m/s²を超える分は足さず、32m/s以上へこの機能で加速しません。既存の各加速自体は変更しません。
- 発動後は3秒の再発動待ち。追走相手の変更・条件からの逸脱で蓄積を失います。
- OFF、復帰、完走、ゲーム終了で蓄積と追加加速を破棄し、再びONにしても持ち越しません。

既定ではP2 test autodriveとStandardのGentle items以外の追加機能がON、Gentle itemsはStandardでOFF・ExperienceでONです。比較時は全OFFから必要なものだけONにできます。

## 検証

`Tools/Validate-Rgp.sh` で設定の固定・予約・個別切替と既存セッションのテストを実行します。Unityメニュー `Racing > Validation > Gameplay Features` はUnity側の検証入口です。

追走の接地・上下別路面・遮蔽物・逆走の検証だけを実行する場合は `Racing > Validation > Slipstream Safety` を使います。

実コースで走行中の切替を検証する場合は、通常の試走へ`RACING_FEATURE_PLAYTEST=1`を追加します。F8の仮想キー入力、全OFF、Gentle items、次レースの予約と復元を行い、`feature-toggles.json`に結果を保存します。検証用入力設定は終了時に復元します。このプローブはEditor専用で、通常ビルドには含めません。

```sh
RACING_FEATURE_PLAYTEST=1 RACING_BALANCE_RUN=equal-control-101 \
RACING_BALANCE_TIME_SCALE=3 RACING_BALANCE_OUTPUT=/private/tmp/racing-feature-playthrough \
Tools/RunBalancePlaytest.sh
```

体験プリセットを最初から指定する実走は、次のように行います。

```sh
RACING_FEATURE_PRESET=experience RACING_BALANCE_RUN=items-402 \
RACING_BALANCE_TIME_SCALE=3 RACING_BALANCE_OUTPUT=/private/tmp/racing-feature-experience \
Tools/RunBalancePlaytest.sh
```

切替プローブはStandard／Experienceの両方に対応し、開始時のプリセットへ復元します。`RACING_CHALLENGE_PLAYTEST=1`を併用すると、検証用の人間代替入力がチューブ左右のラインを狙います。車の位置・速度は変更せず、通常のハンドルとペダルだけを使います。

通常の自動試走はコース端を避けるため、ハンドルアシストの介入時間が0でも正常です。外れそうな入力での補正の成立は、実接地を使ったUnity検証で別に確認しています。

2026年10月19日の検証結果は [Artifacts/GameplayFeatures](../Artifacts/GameplayFeatures/README.md) に保存しました。

人による理解度・楽しさや、実ハンドル／2画面／2音声機器の評価は自動テストと分けて行います。

## コース端のハンドルアシスト

**Course edge steering assist** は既定でONです。通常路面で2輪以上が接地し、前進4m/s以上のとき、0.55秒先の横ずれとコース幅から逸脱を予測します。車幅分を含む1.5mの余白に入りそうな場合だけ、危険度に応じて外向きの入力を道路へ戻す操舵へ置き換えます。切替速度は毎秒90度以内、実際のタイヤ角は既存の速度別上限以内です。危険が消えても0.35秒だけ道路へ向きを揃える処理を維持します。中央走行や既に内側へ戻っている場合は新しい補正を加えません。明らかな逸脱予測では、外へ切り続けていても道路へ戻す操舵を優先します。

補正はタイヤの操舵角だけに加え、生のハンドル入力・ドリフト判定・速度・位置は変更しません。空中、ジャンプ手前、チューブ内、壁面、逆走、妨害・ロケット・復帰・切断中には補正しません。F8でOFFにすると補正量を即時0へ戻します。パネルのassist(s)で補正が働いた累積時間を比較できます。

## 第2段階：指定ジャンプの着地報酬

**Landing success feedback** と **Safe landing reward boost** を別々にF8で切替できます（既定ON）。生成路面の空白として指定されたジャンプだけを対象とし、踏切手前の正常走行→空白上で0.1秒以上の空中移動→進行方向に揃った2輪以上の安定接地0.08秒、という順序で成功判定します。通常の段差・片輪接触・逆走・復帰・妨害・ロケット・壁への衝突では成立しません。

成功時は「着地成功！」と音で知らせ、先12mの曲がりが40度未満で、先15mに次のジャンプがない路面で安全条件を満たす場合だけ、0.5秒・最大2.5m/s²の小加速を与えます。スリップストリームとは強い方だけを適用し、追加報酬を重ねません。既存加速との18m/s²上限、追加報酬による32m/s速度上限も共通です。曲がり角の直前などでは成功通知だけになります。

各ジャンプはプレイヤーごと・周回ごとに1回の飛行試行が対象です。OFF・復帰・失敗で飛行中の状態を破棄し、同じ周回の使用済み記録は保持するため、ON/OFFや踏切への戻りで報酬を稼げません。失敗の減点はありません。F8に成功回数を表示します。

## 第2段階：チューブ内の選べるチャージライン

**Tube side charge lines** は既定ONです。設定された実チューブ内の下側路面を調べ、両側に実路面がある平坦で穏やかな18mを1区間だけ選び、緑の光るラインと進行方向の矢印を生成します。既存クリスタルから14m以上離し、安全な区間を見つけられないコースでは生成しません。中央は追加操作なしで通れる通常ラインです。

左右どちらかの光る帯を前向き・接地した状態で入口から出口まで連続して通ると、最大チャージの25%を追加し「ライン成功！チャージ増加」と通知します。両側を合わせて各プレイヤー1周1回。先に相手が通っても消えません。途中参加・左右の乗換・逆走・滞在・復帰・ロケット・切断では成立させません。満タンでは成功通知を出しません。

F8でOFFにすると帯の表示・途中の判定・通知を即時に消します。既に得たチャージは通常のドリフトチャージとして残ります。ONへ戻しても周回内の取得記録は保持し、スイッチで繰り返し取得できません。今回の対象はチューブ下部の通常路面です。

## P2自動運転とCPUの攻防

F8の **P2 test autodrive** でP2を入力ボットへ切替できます（既定OFF）。タイトル／結果画面の **Start test race - P1 manual / P2 AUTO** は車選択と練習を省略し、通常のカウントダウン付きでテストを開始します。P1は手動です。P2用の実ハンドルが未接続でも自動側は走れます。通常のタイトル操作・練習は変更しません。

自動側は車の位置・向き・速度・回転・実際の接地と前方の道路を観測し、約0.1秒ごとに操舵角とペダルを決めます。前方車への接近時は減速します。踏切の90m手前から車間を整え、ジャンプでは現在の横位置を保ちます。車両の抵抗に必要な踏み込みも計算するため、追従時にアクセル不足で失速するのを防ぎます。車体の位置・速度・周回・順位を直接設定しません。通常のポーズ・復帰ゲートを通り、OFFでは手動入力へ戻してペダルを離すまで再加速を待ちます。OFF時にP2機器が未接続なら接続案内になります。

**CPU overtaking / counterattack** は既定ONです。CPUが先行車に追いつく間は速度を保ち、近くでは10秒の攻撃時間と6秒の抜き返しの余地を作ります。常に人間を勝たせる制御ではなく、CPUの順位も実際の走行で決まります。12m幅でも空いた側へ追い越せるようにし、前方が塞がっているときは減速します。ジャンプ90m手前から前車との間隔を確認し、45m手前から24m/sを目安に進入します。前車が近ければその速度に合わせて間隔を作ります。並走車がいるときは踏切・空中・着地直後に中央へ合流せず、現在の横位置を維持します。

逆方向のコースでも初期グリッドの横位置を維持し、接触後の退避先をコース座標で決めます。接触後の大減速を3秒から0.65秒へ短くし、前車に合わせた速度へ移ります。既存の接触連鎖防止と復帰条件は継続します。OFFでは従来のCPUの速度・進路判断に戻せます。

着地加速は、前輪が先に着いて後輪がまだ空中の場合、成功後最大0.9秒だけ実接地を待ちます。安全条件を満たせなければ加速せず、OFF・復帰・妨害・ロケットで待機も破棄します。

## 結果画面の成功表示

**Result achievement highlight** は既定ONで、F8から結果画面でも即時に切替できます。各人の実際のライン達成・着地・ドリフト解放・追走加速から1件を表示します。順位とタイムは従来どおり表示し、成功がなければ完了周回または検証済みのコース進捗を表示します。未完走ではその表示を明記します。追い上げ順位を推測して称賛することはありません。

結果は各プレイヤーの完走／中断時点で集計を保存するため、リトライや次の組へ前回の成功を持ち越しません。P2自動運転を使用したレースは「自動運転テストの記録」と表示します。
## 高速旋回とハンドル減速（追加）

F8の `High-speed cornering + turn braking` は既定ONです。高速でも操舵の効きを残し、深く切った分だけ路面に沿って減速します。強い減速要求中は持続ブースト加速も抑え、チューブのカーブでブーストに押されて曲がり足りなくなる状況を軽減します。直進加速と低速走行は従来どおりです。OFFは旧操舵との比較に使えます。詳細は [Steering.md](Steering.md) を参照してください。
