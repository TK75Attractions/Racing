# 前進のみの走行検証と復帰修正

## 乗り上げ・復帰先（2026-10-29）

本番と同様に後退入力・方向切替・手動リセットを使わずに検証する。既存のデバッグ後退機能は変更しない。

実際の車両を幅35cmの支持物に乗せたPlay Mode再現で、4輪が浮くと駆動できず、壁接触にも分類されないため自動復帰しなかった。静止物と動くRigidbodyの両方で7秒以上停止した。新たに実際の車体接触と位置の変化を追跡し、アクセル入力があり、4輪が浮き、4秒間2m以上移動できない場合に既存の安全な路面への復帰を使う。ジャンプ中の古い接触、無入力、切断、通常走行は対象外。チューブ走行用の壁法線は独立して維持する。

復帰位置の占有判定は他車に加えて静止障害物も対象とした。中央・左右の候補がすべて塞がれている場合は移動せず待ち、空けば復帰する。復帰時の周回を維持し、ペダルを一度離して再開する既存の手順も維持する。

`ForwardOnlyRecoveryValidation.Run` は本番の車両・接触・自動復帰を使う再現テスト。配置は開始時だけ変更し、試行中は前進入力のみ。静止物・他車相当のRigidbodyへの乗り上げ、無入力、切断、復帰先の静止障害物、通常走行の6条件を検証する。修正後は2種類の乗り上げを約4秒で自動復帰し、全6条件が成功した。既存の `RaceCourseValidation.Run`（壁乗り、スリープ、占有中の待機、順序付き周回等）も成功した。

修正前後の機械可読結果は `Artifacts/ForwardOnlyPlaytest/recovery-before.json` と `recovery-after.json`。

実際の人間による操作性調査、ESP32実機、Windows実行は未検証。
