# RACING 運営マニュアル

ゲームの起動、管理画面での進行、トラブル対応をまとめたスタッフ用手順です。

## 1. 起動と開始前の確認

### 起動する

1. ゲームPC・モニター・ESP32・音声機器を接続する。両ハンドルを中央に置く。
2. ゲームPCにログインし、**ビルド済みのゲームアプリ**を開く。起動時の校正中はハンドルを動かさない。
3. ゲームPCと操作端末の**Tailscaleを接続**する。
4. 操作端末のブラウザーで、共有済みの**Tailscale管理画面URL（`https://…ts.net/`）**を開く。
5. **「UNITY 接続中」**とP1/P2の状態を確認する。閲覧専用の場合は、管理者に操作権限の設定を依頼する。

管理画面の中継が起動していない場合は、ゲームPCで `Tools/DashboardRelay/Start Dashboard.command` を開く。手動起動したターミナルは使用中に閉じない。

### 本番設定を確認する

「音量・出力・デバッグ」で次を確認する。

- **入力モード：P1/P2 実機（ESP32）**
- **P1 ハンドルテスト：通常入力**
- **P2のテスト自動運転：OFF**
- **プリセット・規定周回：当日の設定**。体験は1周・180秒、標準はシーン設定（現行は2周・360秒）。

両席で映像・音声・ハンドル・アクセル・ブレーキを確認し、スタッフで一度通しプレイする。ペダルは踏むと値が変わり、離すと戻ることを確認する。

**再起動後は入力モードを再確認する。** 入力・デバッグ設定は保存されず、起動時の設定に戻る。

## 2. 通常の進行

**タイトル → 車選択 → 練習 → カウントダウン → レース → 結果 → タイトル**

管理画面は「進行コントロール」で操作し、「プレイヤー画面」の個別進行でP1/P2の状態を確認する。車選択・練習は各人で別々に進む。

| 段階 | 進行・操作 |
| --- | --- |
| タイトル | 両者のペダルが離れていることを確認し、**「車選択へ進む」** |
| 車選択 | 左右のハンドルで選択。アクセル短押しで車・カラー・決定欄を切替、長押しで確定。各30秒で、時間切れは表示中の車・色に自動決定 |
| 練習 | ペダル解放後、**加速 → 走りながら旋回 → 光る箱の獲得**。各60秒で、両者が完了または時間切れになると自動で次へ |
| カウントダウン | 3・2・1・GOで開始。カウントダウン中は走行入力が無効 |
| レース | 周回・入力・警告を確認。動けなくなった車は対象の**「復帰」**を使用 |
| ゴール | 完走者は相手の観戦へ切替。残り時間は進行状況で延長される場合があるため画面表示を確認 |
| 結果 | 次の組は**「タイトルへ戻る」**。同じ組の再挑戦は**「もう一度走る」**で、車選択・練習を省略 |

### 練習を手動で終了する場合

1. 車選択・タイトルに残っている人がいれば **「チュートリアルへ進む」**。車選択中は現在の車で確定する。
2. 両者がチュートリアルへ入ったことを確認し、**「カウントダウンへ進む」**。

未完了の課題も終了する。機器異常が原因で進めない場合は、強制進行せず点検する。切断中も準備の制限時間は進む。

### 次の組へ切り替える

両者のタイトル復帰、遠隔入力の終了、機器の状態を確認する。**プリセットはタイトル復帰時に標準へ戻る場合があるため、組ごとに確認する。**

## 3. 復帰・中断・補助操作

### コースへ復帰

「プレイヤー入力」→対象のP1/P2→**「復帰」**を一度押す。遠隔操作の開始は不要。走行中または未完了の練習で使える。

レース中は近くの安全な路面へ戻り、周回は維持する。実際に復帰したことをゲーム画面で確認する。

### 中断メニュー

走行中に **「ESC：両プレイヤーの中断メニューを開閉」** を押し、対象プレイヤーの操作を選ぶ。

| 操作 | 効果 |
| --- | --- |
| 走行に戻る | 対象のメニューを閉じて再開 |
| 前進・後退を切替 | 走行方向を切替。使用後は前進へ戻したことも確認 |
| スタート位置へ | 対象車を開始位置へ戻す。新しいレースにはならない |
| このプレイヤーを中断 | 対象をDNF（未完走）にする。相手が走行中なら観戦へ |

**ESCはレース全体の一時停止ではなく、タイマーや車両の完全停止を保証しない。** メニューが一つでも開いている状態でESCを再度押すと、開いているメニューを閉じる。

### レース全体を終了

走行中に **「レースを終了して結果を表示」** を押す。**未完走者はDNFとして確定する。** 結果の確認だけを目的に押さない。

### 管理画面から入力する

対象の **「遠隔操作を開始」** →アクセル・ブレーキ・左右を操作→**「遠隔操作を終了」**。運転ボタンは押している間だけ有効。終了後は実機のペダルを一度離す。

遠隔操作中は実機より管理画面の入力が優先される。画面移動・切断・進行段階の変更で解除されるため、必要なら開始し直す。

## 4. 設定変更と機器診断

| 項目 | 操作・注意点 |
| --- | --- |
| 音量 | 「音量・出力・デバッグ」の全体・BGM・エンジン音・効果音を調整。両者へ即時反映 |
| 音声出力 | P1/P2の機器を選択。見つからない場合は**「出力機器を再検出」**。同じ機器を両者へ重複指定できない |
| プリセット | 準備開始後の変更は次回へ予約。「現在／次回／予約済み」を確認 |
| 機器診断 | 「機器・接続状態」の対象センサー、または**「原因を調べる」**を押す。「確認済み」と原因の「候補」を区別する |
| 装置の状態確認 | 「ESP32へ送信」→**「接続・状態を照会」**→送信→結果を確認 |
| ハンドルの中央調整 | 両者の走行を止め、両ハンドルを中央へ置く→**「両ハンドルの基準をゼロ調整」**→完了・左右入力を確認 |
| センサー校正 | 機器担当が実施。両者へ影響する。ジャイロ校正中はハンドルを動かさず、完了まで待つ |

装置操作の**「送信」「受付」は完了ではない**。結果未確認・タイムアウト時は連打せず、状態を照会する。配信停止・頻度・姿勢推定の調整は機器担当が行う。

## 5. トラブル対応

基本は **次の開始を止める → 対象・状態を確認 → 対処 → 両席の動作確認 → 再開**。管理画面の映像は約2秒ごとの静止画なので、復帰や停止は現地画面でも確認する。

| 症状 | 確認・対処 |
| --- | --- |
| 管理画面が開かない | PCの電源・ログイン・スリープ、両端末のTailscale、共有URL、中継の起動を確認 |
| UNITY未接続 | ビルド済みアプリが起動・応答しているか確認。ページが開くだけではゲームとの接続完了ではない |
| ボタンが押せない | 接続・操作権限・現在の段階・画面遷移を確認。カウントダウンには両者の練習開始が必要 |
| 操作しても進まない | 最新のゲーム状態を確認。すでに進んでいる場合があるため連打しない |
| ハンドル・ペダルが効かない | ペダル解放、メニュー、遠隔操作中かを確認。実機入力・通常入力・P2自動運転OFFを確認し、機器診断へ |
| 足を離しても入力が残る | 遠隔入力・一定ペダル・自動運転を確認。受信値が戻らない場合は機器点検。惰性走行とは区別する |
| ハンドル中央でも曲がる | 両者を停止してゼロ調整。改善しなければ機器担当へ |
| 横転・落下・引っ掛かり | 対象の「復帰」を使用。メニューが開いていれば閉じてから実行。繰り返す場合は場所を記録 |
| 練習が終わらない | 個別の課題を確認。旋回は走行中の方向転換、箱は実際の接触が必要 |
| 片方だけ終了したい | ESC→対象の「このプレイヤーを中断」。両者終了なら「レースを終了して結果を表示」 |
| 音が出ない | 音量・物理接続・P1/P2の出力先を確認。再検出して選び直す |
| 黒画面・映像停止 | 現地画面も異常か確認。モニター電源・入力切替・ケーブル・拡張表示を確認。完走後の相手画面は観戦表示 |
| 警告が残る | 現在の機器状態と未解決通知を確認。解析エラーは累計なので、件数だけで故障と判断しない |
| ランキングに載らない | DNF・自動運転・一定ペダルなどは対象外。保存エラーは再起動前に記録 |
| アプリ停止・停電・復旧不能 | 体験を中止し機器担当へ。再起動後は実機入力と両席の試走を確認して再開 |

USBの挿し直し・ゼロ調整・校正は両者へ影響するため、走行を止めて行う。Mac版では**P2ウィンドウを閉じるとゲーム全体が終了する**。

体調不良・事故・設備破損・煙や異臭・液体の侵入は直ちに体験を中止し、責任者・会場の対応手順へ引き継ぐ。準備中など終了ボタンが使えない場面でも、安全確保を優先する。

## 6. 終了・引継ぎ

1. 遠隔入力をすべて終了し、必要な記録を確認してゲームアプリを終了する。
2. 周辺機器・PCを会場の終了手順に従って停止する。
3. 障害があれば、**時刻・対象P1/P2・症状／警告・行った処置・未対応事項**を残す。
