# レース管理画面の閲覧・操作マニュアル（参加者向け）

スマホ・タブレット・PCから、離れた場所にあるレース管理画面を閲覧・操作するための手順です。初回はTailscaleの登録、アプリのインストール、招待の承認を行います。2回目以降は、Tailscaleを接続して管理画面URLを開くだけです。

Tailscaleは、招待されたPCへ接続するためのアプリです。閲覧中はアプリの接続をオンにしておきます。ゲーム用PCと同じWi-Fiにいる必要はなく、自宅のWi-Fiやスマホの4G・5Gから利用できます。

## 1. 手元に用意するもの

- 閲覧に使うスマホ・タブレット・PCと、インターネット接続
- 自分のGoogleなど、Tailscaleのログイン画面で選べるアカウント
- 主催者から届いた「共有招待リンク」と「管理画面URL」

**共有招待リンク**は初回に接続権限を受け取るためのリンクです。**管理画面URL**は、毎回レースの情報を見るための `https://～.ts.net/` というURLです。この2つは用途が異なります。

## 2. 自分のTailscaleアカウントを作る（初回のみ）

1. ブラウザーで[Tailscale公式サイト](https://tailscale.com/)を開き、**Get Started**を選びます。
2. Googleなど、使いたい認証方法を選び、**自分のアカウント**でログインします。主催者のアカウントを借りる必要はありません。
3. 利用目的などの初期案内に従って登録を完了します。自分用のネットワーク（tailnet）が作成された場合は、そのまま使います。

すでにTailscaleを使っている人は、そのアカウントを使用できます。招待を承認するブラウザーと、次の手順のTailscaleアプリで、同じ認証方法・同じアカウントを使ってください。[登録の公式案内](https://tailscale.com/docs/how-to/quickstart)

## 3. 閲覧する端末にアプリを入れる（端末ごとに初回のみ）

| 使う端末 | インストール方法 |
| --- | --- |
| iPhone／iPad | App Storeで「Tailscale」を検索してインストール |
| Android | Google Playで「Tailscale」を検索してインストール |
| Windows／Mac | [公式ダウンロードページ](https://tailscale.com/download)から自分のOS用をインストール |

1. Tailscaleアプリを開き、**Log in／ログイン**を選びます。
2. 手順2で登録したアカウントでログインします。
3. 初回にVPN構成の追加や接続許可が表示されたら、案内に従って許可します。
4. 接続をオンにし、**Connected／接続済み**になったことを確認します。

スマホではVPNの接続確認が表示されることがあります。[iPhone／iPadの公式案内](https://tailscale.com/docs/install/ios)、[Androidの公式案内](https://tailscale.com/docs/install/android)

Unityやゲーム本体のインストールは不要です。ブラウザーを開く端末にTailscaleを入れてください。スマホだけに入れても、別のPCのブラウザーからは接続できません。

## 4. 主催者の共有招待を承認する（初回のみ）

1. 主催者から届いた**共有招待リンク**をブラウザーで開きます。
2. ログインを求められたら、Tailscaleアプリと同じ自分のアカウントでログインします。
3. 招待した人と共有するPC名が主催者からの案内と一致することを確認し、共有を承認するボタンを押します。
4. 承認が完了したら、主催者へ「招待を承認しました」と伝えます。

自分のtailnetに主催者のPCが共有される方式です。主催者のtailnetへ切り替える操作は不要です。招待リンクは他の人へ転送しないでください。[端末共有の公式案内](https://tailscale.com/docs/features/sharing)

「承認する権限がない」と表示される場合は、会社・学校などの管理されたtailnetを使っている可能性があります。そこの管理者に相談するか、個人アカウントの利用が認められている場合は個人用のTailscale環境を使い、アプリも同じアカウントに合わせて招待を承認します。

## 5. 管理画面を開く

1. 主催者から案内された閲覧時間になったら、閲覧する端末のTailscaleを**接続済み**にします。
2. Safari、Chrome、Edgeなどのブラウザーで、主催者から届いた**管理画面URL**を開きます。メールやチャット内の簡易ブラウザーで開けない場合は、URLをコピーして通常のブラウザーのアドレス欄に貼り付けます。
3. 画面に**Tailscale / WebSocket**と表示され、ゲームの状態や入力値などが更新されることを確認します。
4. 管理画面URLをブックマークしておくと、次回から開きやすくなります。

レースの状態、プレイヤーのプレビュー、入力値、通信履歴などを閲覧できます。プレビューは一定間隔で更新される画像です。

主催者の設定後は、招待された人もレース開始、チュートリアルへの進行、カウントダウン開始、結果表示、再挑戦、タイトル復帰や装置へのコマンド送信ができます。**操作は実際のゲームや装置に反映されるため、主催者と他の担当者に声をかけてから操作してください。** 操作後は画面の状態や結果表示で反映を確認します。

現在の段階に合わない操作や、Unity未接続・状態更新停止中の操作は無効になります。装置の操作には機器の接続も必要です。「閲覧専用です」と表示される場合は、主催者へ操作権限の設定確認を依頼し、設定後にページを再読み込みしてください。

URLは主催者が送った `https://～.ts.net/` を省略せずに使います。PC名だけに短くしたり、`http://127.0.0.1:8766/` に置き換えたりしないでください。共有された端末の名前解決には完全な名前が必要です。[共有端末のURLについて（公式）](https://tailscale.com/docs/features/sharing#sharing-and-magicdns)

## 6. 2回目以降と終了時

次回は、**Tailscaleを接続 → 管理画面URLを開く**の2手順で閲覧できます。招待を毎回承認する必要はありません。

閲覧を終えたらブラウザーのタブを閉じます。Tailscaleを他の用途で使わない場合は、アプリで接続をオフにして構いません。主催者が共有を解除した後は、再び招待してもらうまで接続できません。

## 困ったとき

| 状況 | 対処 |
| --- | --- |
| 招待リンクが無効／使用済み | 主催者に新しい招待リンクを依頼します |
| ページが開かない | この端末のTailscaleが接続済みか、招待を承認したアカウントとアプリのアカウントが同じか、管理画面URLを正しくコピーしたかを確認します |
| VPNをオンにできない | 他のVPNが接続中なら、利用上問題のない範囲で切り替えます。会社・学校の管理端末では管理者へ相談します |
| ページは開くが「UNITY 未接続」「再接続中」 | 主催者へ連絡します。ゲーム用PCでUnityや中継の起動確認が必要です |
| ファイルが保存される／502 | 保存されたファイルは開かず、主催者へ連絡します。復旧後、ブラウザーで管理画面URLを開き直します |
| 操作ボタンが押せない | 現在の進行段階・Unityや装置の接続状況を確認。「閲覧専用」と表示される場合は主催者へ操作権限の確認を依頼し、設定後に再読み込みします |
| 403／アクセス拒否 | 使用中のTailscaleログイン名を添えて主催者へ連絡します |
| 表示が不安定 | 余分な管理画面タブを閉じ、1つのタブで開き直します |

解決しない場合は、**使っている端末・Tailscaleの接続状態・表示されたエラー・発生時刻**を主催者へ伝えてください。パスワードや認証コードを送る必要はありません。
