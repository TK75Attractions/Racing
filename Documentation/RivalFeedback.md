# 接近演出と相手名付きの命中通知

各プレイヤーの `RivalFeedbackHUD` が、自分のレース中だけ接近演出と自分が与えた妨害の結果を表示する。P1/P2/CPUを同じ対象として扱い、名前は順位表と同じ `RaceParticipant.Label`（P1、P2、CPU 1、CPU 2）を使う。車両の入力・速度・アイテム効果の強さは変更しない。

## 接近

- 前方の相手：相手の上に厚みのある金色の3D矢印を置き、相手を指す。「前方に P2 / 12 m」のように名前と距離も表示する。矢印はUIの縮尺を受けないワールド座標のMeshで、Colliderなし。カメラの描画開始コールバックで、そのプレイヤーのメインカメラにだけ描画する。
- 後方の相手：画面の外周12%に赤いグラデーションを重ね、名前付きの接近表示を出す。中央76%には色を重ねない。危険度に応じて滑らかに濃くなり、明滅の強い全画面フラッシュにはしない。
- 0.1秒間隔で実際の位置と相対速度を調べる。前方55m／後方40m以内で毎秒1m以上接近している相手、または至近距離（前方18m／後方14m）の相手を対象とする。複数いる場合は各方向で最も危険度の高い相手を選ぶ。
- 自車の向きを基準に前後を分け、前後差1.5m未満の並走では切り替えをちらつかせない。横9m超、車体の上方向で高低差4.5m超、コースの最短距離差70m超の相手は除く。静的な壁に遮られる相手もRaycastで除外する。周回境界は循環するコース距離で判定するため、周回遅れも物理的に近ければ対象になる。
- ゴール・中断済み、非表示、復帰保護中の車両を除く。自分のゴール後の観戦画面へ警告を持ち越さない。

## 命中通知

`CarItemEffects.AttackLanded` は、効果の成立後に発動者へ対象と `ItemImpactKind` を返す。通知は次の4種類。

| 成立した結果 | 通知例 |
| --- | --- |
| 設置したオイルで相手が滑った | CPU 1 がオイルでスリップ！ |
| 自分のシールド衝突で相手がスピンした | P2 をスピンさせた！ |
| 相手のハンドル反転が成立した | CPU 2 のハンドルを反転！ |
| その反転が有効な間に静的な壁へ衝突した | P2 が反転中に壁へ接触！ |

オイルは油だまりが発動者を保持する。油だまりの消費（シールド／ロケットで滑らずに消す場合）と、オイル妨害の成立を区別する。自己被弾、防御・復帰保護・連続被弾保護で拒否された攻撃、無効化済みの車には成功を出さない。複数Colliderのオイル接触、既にスピン中の再接触でも通知を重ねない。

反転中の壁接触は、効果を与えた発動者を保持して実際のCollisionで確認する。静的な壁へ相対速度3m/s以上で接触し、法線のY絶対値が0.2未満の場合だけ。一度の反転につき一度で、チューブの走行面・他車・効果終了後の接触は除く。人間の混乱を推測して成功とせず、「反転中に接触した」という観測できた事実を表示する。

通知は攻撃したプレイヤーの画面に約2.6秒表示し、末尾をフェードする。複数対象は最大3件待機。同じ相手の反転通知の表示中に壁接触が起きたら、通知を更新する。被害者側の既存アイテム表示や、接続・ペダル・ジャンプの案内とは別枠に配置する。

## ON/OFFと確認

F8に既定ONの独立した2項目を追加した。

- **Rival proximity: 3D arrow / rear red edges**
- **Named outgoing item hit confirmations**

F8パネルは項目増加に合わせてスクロール可能にした。画面サイズを超えて新しい項目が隠れない。OFFで表示と保留通知を消す。レース終了・次のレースでも対象へのイベント購読を切り替えて古い通知を残さない。

```sh
bash Tools/Validate-Rgp.sh
RACING_BALANCE_SKILL_SUITE=1 RACING_BALANCE_RUN=human-fast-control-7102 \
RACING_BALANCE_TIME_SCALE=1 RACING_BALANCE_VIDEO=1 RACING_BALANCE_WINDOW_SECONDS=23 \
RACING_RIVAL_FEEDBACK_CHECK=1 \
RACING_BALANCE_OUTPUT=Logs/RivalFeedback/FinalReady bash Tools/RunBalancePlaytest.sh
```

`RivalFeedbackPlaytestProbe` は、人間に近い反応間隔でハンドル角・ペダルを入力する既存ボットによる通常走行で前後の表示とP1/P2の名前付き通知を観測する。映像で妨害を確実に確認するため、指定した時刻に通常の `UseItem` からテスト用のコンフューズを発動する。レース車両の姿勢や速度は書き換えない。

これとは別に、コース外に専用の試験車体を生成し、防御、自己被弾、無効化、連続被弾保護、オイルの発動者保持を確認する。その試験車体同士の実際のオイルTrigger、シールドCollision、静的な壁へのCollisionでも成立イベントを確認する。専用車体の配置・速度は試験用で、通常ボットの走行データとは区別する。`RACING_REBUILD_HUD_FONTS=1` で新しい日本語通知を含む静的フォントの再生成も強制できる。
